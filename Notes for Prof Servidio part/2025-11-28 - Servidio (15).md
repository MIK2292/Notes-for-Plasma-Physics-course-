# Magnetostatic equilibria
We consider the energy with $\bar{U} = 0$  
$$
\begin{align}
\frac{d}{dt} \left\langle  \frac{B^2}{2}  \right\rangle &= - \eta \langle J^2  \rangle 
\end{align}
$$
we use Fourier transform (we leave behind the norm constant)
$$
\begin{align}
 \bar{B} (\bar{x}, t) = \sum_{\bar{k}} \tilde{\bar{B}} (\bar{k}, t) e^{ i\bar{k} \cdot \bar{x} } , && \tilde{B}_{j} (\bar{k},t) \in \mathbb{C}
\end{align} 
$$
eg.
$$
 B_{x} (x,y,z,t) = \sum_{k_x = -\infty}^{\infty} \sum_{k_y = -\infty}^{\infty} \sum_{k_z = -\infty}^{\infty} \tilde{B} _{x} (k_{x}, k_{y}, k_{z}, t) e^{i (k_{x}x+k_{y}y+k_{z}z) }
$$
and
$$
\tilde{\bar{B}}(\bar{k},t) = \frac{1}{V} \int \bar{B}(\bar{x},t) e^{ -i \bar{k} \cdot \bar{x} } \, d^3x = \langle \bar{B}(\bar{x}, t) e^{ -i\bar{k}\cdot \bar{x} } \rangle 
$$
We need to transform $B^2$ 
$$
 B^2 = \bar{B} \cdot \bar{B} = \left( \sum_{\bar{k}} \tilde{\bar{B}} (\bar{k}, t) e^{ i\bar{k} \cdot \bar{x} } \right) \cdot \left( \sum_{\bar{l}} \tilde{\bar{B}} (\bar{l}, t) e^{ i\bar{l} \cdot \bar{x} } \right)
$$
so
$$
 \frac{1}{2}\frac{ \partial B^2 }{ \partial t }  = \frac{ \partial }{ \partial t } \sum_{\bar{k}} \sum_{\bar{l}} \frac{\tilde{\bar{B}} (\bar{k}, t) \tilde{\bar{B}} (\bar{l}, t)}{2} e^{ i(\bar{k} + \bar{l}) \cdot \bar{x} } 
$$
and the energy can be written as
$$
\begin{align}
\frac{d}{dt} \left\langle  \frac{ B^2 }{2} \right\rangle &= \frac{d}{dt} \frac{1}{V}  \sum_{\bar{k}} \sum_{\bar{l}} \int \frac{\tilde{\bar{B}} (\bar{k}, t) \tilde{\bar{B}} (\bar{l}, t)}{2} e^{ i(\bar{k} + \bar{l}) \cdot \bar{x} } \, d^3x=  \\[.8em]
 &=  \frac{d}{dt}  \sum_{\bar{k}} \sum_{\bar{l}} \frac{\tilde{\bar{B}} (\bar{k}, t) \tilde{\bar{B}} (\bar{l}, t)}{2} \frac{1}{V} \int  e^{ i(\bar{k} + \bar{l}) \cdot \bar{x} } \, d^3x
\end{align}
$$
We use the orthonormality condition in the integral 
$$
\frac{1}{V} \int  e^{ i(\bar{k} + \bar{l}) \cdot \bar{x} } \, d^3x = \delta_{\bar{k},-\bar{l}}
$$
so
$$
\begin{align}
\frac{d}{dt}  \frac{\left\langle   B^2 \right\rangle}{2} &= \frac{d}{dt}  \sum_{\bar{k}} \sum_{\bar{l}} \frac{\tilde{\bar{B}} (\bar{k}, t) \tilde{\bar{B}} (\bar{l}, t)}{2} \delta_{\bar{k},-\bar{l}} = \\[.8em]
&= \frac{d}{dt}  \sum_{\bar{k}} \frac{\tilde{\bar{B}} (\bar{k}, t) \tilde{\bar{B}} (-\bar{k}, t)}{2} = \\[.8em]
&= \frac{d}{dt} \sum_{\bar{k}} \frac{\lvert \tilde{\bar{B}}(\bar{k},t) \rvert^2}{2}  
\end{align}
$$
where we used the reality condition ($\bar{B}$ real, Fourier transformation of $\bar{B}$ is symmetric)
$$
\begin{align}
 f \in \mathbb{R} &&\implies && f(k) = f(-k)
\end{align}
$$

We can do the same reasoning also for $\bar{J}$  in order to find $J^2$.
$$
\bar{J} =  \nabla \times \bar{B} = \nabla \times \left[ \sum_{\bar{k}} \tilde{\bar{B}} (\bar{k}, t) e^{ i\bar{k} \cdot \bar{x} }  \right] = \sum_{\bar{k}} i [\bar{k} \times \tilde{\bar{B}} (\bar{k}, t)] e^{ i\bar{k} \cdot \bar{x} }
$$
so
$$
 J^2 = \sum_{\bar{k}} \sum_{\bar{l}} i^2 [\bar{k} \times \tilde{\bar{B}} (\bar{k},t)] \cdot [\bar{l} \times \tilde{\bar{B}} (\bar{l},t)] e^{ i (\bar{k} + \bar{l}) \cdot \bar{x} }
$$
and
$$
 \langle  J^2 \rangle = - \frac{1}{V} \int \sum_{\bar{k}} \sum_{\bar{l}} [\bar{k} \times \tilde{\bar{B}} (\bar{k},t)] \cdot [\bar{l} \times \tilde{\bar{B}} (\bar{l},t)] e^{ i (\bar{k} + \bar{l}) \cdot \bar{x} } \, d^3x = - \sum_{\bar{k}} \lvert  \bar{k} \times \tilde{\bar{B}}(\bar{k},t) \rvert ^2
$$
We notice that 
$$
\begin{align}
 \nabla \cdot \bar{B} = 0 && \implies && \bar{k} \cdot \tilde{\bar{B}} (\bar{k},t) =0 && \implies && \bar{k} \perp \tilde{\bar{B}} (\bar{k},t) 
\end{align}
$$
so
$$
\langle J^2 \rangle  = - \sum_{k} k^2 \lvert \tilde{\bar{B}}(\bar{k},t) \rvert^2 = - 2\sum_{k} k^2 E_{b} (\bar{k},t)
$$
where we used
$$
 E_{b}(\bar{k},t) \equiv  \frac{\lvert \tilde{\bar{B}}(\bar{k},t) \rvert^2}{2} 
$$
so our original equation can be written as
$$
\begin{align}
\frac{d}{dt} \left\langle  \frac{B^2}{2}  \right\rangle &= - \eta \langle J^2  \rangle &&\implies&&  \frac{d}{dt}  \left[ \sum_{k} E_{b}(\bar{k},t) \right] = -2\eta \sum_{\bar{k}} k^2 E_{b} (\bar{k},t)
\end{align}
$$

\begin{align}

# Taylor Force Free States
J.B. Taylor, PRL 33, 1139 (1974) 
In mangetostatic equilibria ($\bar{U} = 0, \nu = 0, \eta \neq 0$) we have 2 invariants
$$
 \begin{align}
E = \left\langle   \dfrac{B^2}{2}  \right\rangle ;&&
 H_{m} = \left\langle   \dfrac{\bar{a}\cdot\bar{B}}{2}  \right\rangle 
\end{align}
$$
We will solve a variation minimization problem
$$
\begin{align}
 \delta (E-\mu H_{m}) = 0 && \implies && \delta \int \left[ \frac{B^2}{2} - \frac{\mu (\bar{a} \cdot \bar{B})}{2} \right] \, d^3x = 0
\end{align}
$$
Using the Euler-Lagrange equations
$$
\begin{align}
  \delta \int_{-\infty}^{\infty} \mathscr{L} (t, x(t), \dot{x}(t)) \, dt = 0 &&\implies && \frac{ \partial \mathscr{L} }{ \partial q } - \frac{d}{dt}  \frac{ \partial \mathscr{L} }{ \partial \dot{q} }  = 0
\end{align}
$$
We can extend it to multidimentional lagrangian
$$
 \int_{\Omega} \mathscr{L} (x_{1},x_{2},\dots,x_{n-1}, x_{n}, f_{1}, f_{2}, \dots , f_{m}, f_{i,j}, \dots) \,  d^d x = 0
 $$
with 
$$
 f_{i,j} \equiv \frac{ \partial f_{i} }{ \partial x_{j} } 
$$
Generalized Euler-Lagrange equations
$$
\begin{align}
\frac{ \partial \mathscr{L} }{ \partial f_{i} } - \sum_{j=1}^n \frac{ \partial }{ \partial x_{j} } \left( \frac{ \partial \mathscr{L} }{ \partial f_{i,j} }  \right) = 0  &&\implies &&
\begin{cases}
\frac{ \partial \mathscr{L} }{ \partial f_{1} } - \sum_{j=1}^n \frac{ \partial }{ \partial x_{j} } \left( \frac{ \partial \mathscr{L} }{ \partial f_{1,j} }  \right) = 0  \\[.8em]
\frac{ \partial \mathscr{L} }{ \partial f_{2} } - \sum_{j=1}^n \frac{ \partial }{ \partial x_{j} } \left( \frac{ \partial \mathscr{L} }{ \partial f_{2,j} }  \right) = 0  \\[.8em]
\dots\dots  \\[.8em]
\frac{ \partial \mathscr{L} }{ \partial f_{m} } - \sum_{j=1}^n \frac{ \partial }{ \partial x_{j} } \left( \frac{ \partial \mathscr{L} }{ \partial f_{m,j} }  \right) = 0 
\end{cases}
\end{align}
$$
We take $f_{1}$ as $\bar{a}$, the lagrangian is 
$$
\begin{align}
 \mathscr{L} &= \frac{B^2}{2} - \mu \frac{ \bar{a}\cdot \bar{B}}{2} =  \frac{\left( \nabla \times \bar{a} \right) ^2}{2} - \mu \frac{ \bar{a}\cdot \left( \nabla \times \bar{a} \right)}{2} =  \\[.8em]
&= \frac{(\partial_{y} a_{z} - \partial_{z} a_{y})^2}{2} + \frac{(\partial_{z} a_{x} - \partial_{x} a_{z})^2}{2} + \frac{(\partial_{x} a_{y} - \partial_{y} a_{x})^2}{2} +  \\[.8em]
&\ \ \ \ \, - \frac{\mu}{2} a_{x} (\partial_{y} a_{z} - \partial_{z} a_{y}) - \frac{\mu}{2} a_{y} (\partial_{z} a_{x} - \partial_{x} a_{z}) - \frac{\mu}{2} a_{z} (\partial_{x} a_{y} - \partial_{y} a_{x})
\end{align}
$$
The Euler-Lagrange equation for $i=1$ (along $\hat{x}$) is
$$
 \frac{ \partial \mathscr{L} }{ \partial a_{x} } - \partial_{x} \left[ \frac{ \partial \mathscr{L} }{ \partial (\partial_{x} a_{x}) }  \right]   - \partial_{y} \left[ \frac{ \partial \mathscr{L} }{ \partial (\partial_{y} a_{x}) }  \right]  - \partial_{z} \left[ \frac{ \partial \mathscr{L} }{ \partial (\partial_{z} a_{x}) }  \right]   = 0
$$
First term (we only differentiate $a_{x}$) (using $\nabla \times \bar{a} = \bar{B}$)
$$
 \frac{ \partial \mathscr{L} }{ \partial a_{x} } = - \frac{\mu}{2} (\partial_{y} a_{z} - \partial_{z} a_{y}) = - \frac{\mu}{2} B_{x}
$$
Second term (we don't have anywhere $\partial_{x} a_{x}$)
$$
 \partial_{x} \left[ \frac{ \partial \mathscr{L} }{ \partial (\partial_{x} a_{x}) }  \right] = 0 
$$
Third term (using $\nabla \times \bar{a} = \bar{B}$)
$$
\partial_{y} \left[ \frac{ \partial \mathscr{L} }{ \partial (\partial_{y} a_{x}) }  \right] = \partial_{y} \left[ -\frac{2 (\partial_{x} a_{y} - \partial_{y} a_{x})}{2} + \frac{\mu}{2} a_{z} \right] = \partial_{y}\left[ - B_{z} + \frac{\mu}{2} a_{z} \right]
$$
Fourth term
$$
\partial_{z} \left[ \frac{ \partial \mathscr{L} }{ \partial (\partial_{z} a_{x}) }  \right] = \partial_{z} \left[ \frac{2 (\partial_{z} a_{x} - \partial_{x} a_{z})}{2} - \frac{\mu}{2} a_{y} \right] = \partial_{z} \left[ B_{y} - \frac{\mu}{2} a_{y} \right]
$$
We put everything together
$$
 - \frac{\mu}{2} B_{x} - 0 - \partial_{y}\left[ - B_{z} + \frac{\mu}{2} a_{z} \right] - \partial_{z} \left[ B_{y} - \frac{\mu}{2} a_{y} \right] = 0
$$
so
$$
\begin{align}
 &- \frac{\mu}{2} B_{x} + \partial_{y} B_{z} - \frac{\mu}{2} \partial_{y}a_{z} - \partial_{z} B_{y} + \frac{\mu}{2} \partial_{z} a_{y} = 0  \\[.8em]
\implies&- \frac{\mu}{2} B_{x}  - \frac{\mu}{2} \left( \partial_{y}a_{z} - \partial_{z} a_{y} \right)  + \partial_{y} B_{z} - \partial_{z} B_{y} = 0  \\[.8em]
\implies&- \frac{\mu}{2} B_{x}  - \frac{\mu}{2} B_{x}  + \partial_{y} B_{z} - \partial_{z} B_{y} = 0 
\end{align}$$
and finally (using $\bar{J} = \nabla \times \bar{B}$)
$$
-\mu B_{x} = - (\partial_{y} B_{z} - \partial_{z} B_{y}) \equiv J_{x}
$$
from the other equations we get
$$
\begin{align}
\begin{cases}
J_{x} = \mu B_{x} \\[.6em]
J_{y} = \mu B_{y}  \\[.6em]
 J_{z} = \mu B_{z}
\end{cases} &&\implies&& \bar{J} = \mu \bar{B}
\end{align}
$$
the same reasoning works for $\bar{\omega} = \mu \bar{U}$.

Force-free state, Taylor state
$$
 \bar{B} \to \nabla \times \bar{B} = \bar{J} = \mu \bar{B}
$$

 \begin{cases}
 \bar{U} = \alpha \bar{B} \\[.6em]
\nabla \times \bar{B} = \beta \bar{B} \\[.6em]
\nabla \times \bar{U} = \gamma \bar{U}
\end{cases}
$$
These equations describe an MHD solution
$$
\begin{align}
 \frac{ \partial \bar{U} }{ \partial t } &= - \bar{U} \cdot \nabla \bar{U}+ \bar{J} \times \bar{B} - \nabla P = \cancel{ \bar{U} \times \bar{\omega} } + \cancel{ \bar{J} \times \bar{B} } - \nabla \left( P+ \frac{U^2}{2} \right)
\end{align}
$$
where we used
$$
\begin{align}
\bar{A}\times \left(\nabla \times \bar{B} \right) = \left( \nabla \bar{B} \right) \cdot \bar{A} - \left( \bar{A} \cdot \nabla \right) \bar{B}; && \bar{\omega} = \nabla \times \bar{U}
\end{align}
$$
Also, using $\bar{U} = \alpha \bar{B}$, we get
$$
\frac{ \partial \bar{B} }{ \partial t } = \cancel{ \nabla \times (\bar{U} \times \bar{B}) } = 0
$$

Assumptions:
$$
\begin{align}
 \bar{U} = 0;&&\nabla \times \bar{B} = \mu \bar{B}

$$
so
$$
\begin{cases}
 \nabla \times (\nabla \times \bar{B} ) =  \nabla ( \nabla \cdot \bar{B} ) - \nabla^2\bar{B} = - \nabla^2\bar{B} \\[.8em]
 \nabla \times (\nabla \times \bar{B} ) = \mu \nabla \times \bar{B} = \mu^2 \bar{B}
\end{cases}
$$
then
$$
\begin{align}
 \nabla^2 \bar{B} + \mu^2 \bar{B} = 0 &&\implies &&(\nabla^2 + \mu^2) \bar{B} = 0
\end{align}
$$
We isolate the $B_{z}$ component and use the cylindrical laplacian definition
$$
 \left( \frac{ \partial^2  }{ \partial r^2 } + \frac{1}{r} \frac{ \partial  }{ \partial r } + \frac{1}{r^2}\frac{ \partial^2  }{ \partial \theta^2 } + \frac{ \partial^2  }{ \partial z^2 } + \mu^2 \right) B_{z} = 0
$$
We apply the cosine transform over $\theta$ and $z$ 
$$
B_{z} (r,\theta,z) = \sum_{m=0}^{\infty} \sum_{k=0}^{\infty} \tilde{B}_{z} (r,\theta,z) \cos (m \theta + kz)
$$
So the laplacian can be written as
$$
\left( \frac{ \partial^2  }{ \partial r^2 } + \frac{1}{r} \frac{ \partial  }{ \partial r } + \mu^2 - k^2 - \frac{m^2}{r^2} \right) \tilde{B}_{z}(r,m,k) = 0
$$
and taking
$$
\alpha \equiv \sqrt{ \mu^2 - k^2  }
$$
we get
$$
\left( \frac{ \partial^2  }{ \partial r^2 } + \frac{1}{r} \frac{ \partial  }{ \partial r } + \alpha^2 - \frac{m^2}{r^2} \right) \tilde{B}_{z}(r,m,k) = 0
$$
which is the **Bessel differential equation**, which has the following (unique) solution 
$$
 \tilde{B}_{z} (r,m,k) = J_{m} (\alpha r)
$$
So we can substitute this into the cosine decomposition for $B_{z}$ 
$$
 B_{z} (r,\theta,z) = \sum_{m=0}^{\infty} \sum_{k=0}^{\infty} J_{m} (\alpha r) \cos (m \theta + kz)
