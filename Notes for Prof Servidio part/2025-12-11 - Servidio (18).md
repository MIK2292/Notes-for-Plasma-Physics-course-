# Tearing instability (continuing)
Before we obtained the momentum equation
$$
 \gamma (v_{y}'' - k^2 v_{y}) = ik [B_{0x} (b_{y}'' - k^2 b_{y}) - b_{y} B_{0x}'']
$$
For the magnetic field equation we have
$$
\begin{align}
 &\frac{ \partial \bar{b} }{ \partial t } = \nabla \times (\bar{v}_{1} \times \bar{B})  + \eta \nabla ^2 \bar{b} \\[.8em]
\implies&  \frac{ \partial  }{ \partial t } \left[ b_{y}(y) e^{ \gamma t + ikx }  \right]  = - \partial _{x} \left[ -v_{y}(y) B_{0x} e^{ \gamma t + ikx }  \right] + \eta (\partial_{xx}^2 + \partial_{yy}^2) b_{y}(y) e^{ \gamma t + ikx }  \\[.8em]
\implies&  \gamma b_{y} e^{ \gamma t + ikx } = B_{0x} ikv_{y} e^{ \gamma t + ikx }+ \eta \left( -k^2 b_{y} + b_{y}'' \right)  e^{ \gamma t + ikx } \\[.8em]
\implies& \gamma b_{y}   = B_{0x} ikv_{y}  + \eta \left( -k^2 b_{y} + b_{y}'' \right)
\end{align}
$$
We rename the only two variables as
$$
 \begin{align}
v_{y}\to v ,&& b_{y}\to b
\end{align}
$$
so
$$
 \begin{cases}
 \gamma (v'' - k^2 v) = ik [B_{0x} (b'' - k^2 b) - b_{y} B_{0x}''] \\[.8em]
\gamma b = B_{0x} ikv  + \eta (-k^2 b + b'') 
\end{cases}
$$
with $B_{0x}= B_{0x}(y)$

## Inside
We have
$$
\begin{align}
 \eta \neq 0, && B_{0x} \sim 0 \ll v,b
\end{align}
$$
We also have that the derivative along $x$ is much lower than the derivative along $y$ 
HERE right? why is it right?
$$
\begin{align}
 kf \ll \frac{ \partial f }{ \partial y } ,&& k\to 0
\end{align}
$$
recalling $\partial _y f = f'$ we approximate 
$$
 \begin{align}
v'' \simeq \frac{v}{\delta^2}, && b'' \simeq \frac{b}{\delta^2} 
\end{align}
$$
we use this in the equations
$$
\begin{align}
B_{0x}b'' \sim B_{0x} \frac{b}{\delta^2},
&& b B_{0x}'' \sim b \frac{B_{0x}}{a^2}
\end{align}
$$
with $a$ spatial scale of the variation of $b$.
So 
$$
\begin{align}
 B_{0x} b'' \ll B_{0x}'' b && (\delta \ll a)
\end{align}
$$
**Equation of momentum inside** 
Recall 
$$
 \begin{cases}
 \gamma (v'' - k^2 v) = ik [B_{0x} (b'' - k^2 b) - b_{y} B_{0x}''] \\[.8em]
\gamma b = B_{0x} ikv  + \eta (-k^2 b + b'') 
\end{cases}
$$
We consider only the small $k$ and $B_{0x} \sim 0$.
From the **momentum equation** 
$$
\begin{align}
  \gamma v'' - \gamma k^2 v = ik \left[ B_{0x} b'' - k^2 B_{0x} b - b B_{0x}'' \right] 
\end{align}
$$
we approximate it as (recall $kf \ll  \partial f / \partial y$) 
$$
\gamma v'' \simeq  ik (B_{0x}b'')
$$
The **magnetic field equation** becomes
$$
 \gamma b \simeq ik B_{0x}v + \eta (b'' - k^2b)
$$
which gets approximated to
$$
 \gamma b \simeq \eta b''
$$

### Outside
We assume
$$
\begin{align}
 \eta \simeq 0
, && B_{0x} \gg v,b
\end{align}
$$
**Equation of momentum** outside 
$$
 \gamma (v'' - k^2v)= ik \left[ B_{0x} (b''-k^2b) - bB_{0x}'' \right] 
$$
so we approximate ($v$ is of the same order of $b$, but the $b$ is multiplied by $B_{0x}$ which is huge)
$$
ik \left[ B_{0x} (b''-k^2b) - bB_{0x}'' \right]  \simeq 0
$$
and dividing by $B_{0x}$ we get
$$
b'' - k^2 b - \frac{B_{0x}''}{B_{0x}} b \simeq 0
$$
The **magnetic field equation** is 
$$
 \gamma b = ikB_{0x} v + \eta \left( b'' - k^2b \right) 
$$
wich gets approximated to 
$$
 \gamma b \simeq ik B_{0x} v
$$

### Results
So inside we have
$$
 \begin{cases}
\gamma v'' \simeq  ik (B_{0x}b'') && (1) \\[.8em]
 \gamma b \simeq \eta b'' &&(2)
\end{cases}
$$
and outside we have
$$
 \begin{cases}
b'' - k^2 b - \dfrac{B_{0x}''}{B_{0x}} b \simeq 0 && (3) \\[.8em]
 \gamma b \simeq ik B_{0x} v && (4)
\end{cases}
$$
we remember that $B_{0x} = B_{0x} (y)$ so this makes things difficult.
PIC delta/2
![[IMG_20251211_111431148_HDR~2.jpg|300]]
We introduce a disconinuity parameter $\Delta'$ 
$$
 \Delta' \equiv a \frac{ b'\left( \frac{\delta}{2} \right) - b'\left( -\frac{\delta}{2} \right) }{b\left( \frac{\delta}{2} \right)} = 2\frac{ a }{b\left( \frac{\delta}{2} \right)} \left| b'\left( \frac{\delta}{2} \right)  \right|
$$
from symmetry.
We can write the second derivative of $b$ as
(we have $\delta$ with power $1$ because we are evaluationg it from the first derivative)
$$
 b'' \left( \frac{\delta}{2} \right) \simeq \frac{ b'\left( \frac{\delta}{2} \right) - b'\left( -\frac{\delta}{2} \right) }{\delta} = \frac{\Delta' \cdot b\left( \frac{\delta}{2} \right)}{a \delta}
$$
and for $v$ we have 
$$
 v'' \simeq - \frac{v\left( \frac{\delta}{2} \right)}{\delta^2}
$$
it must be odd otherwise we have compressibility
HERE why? shouldn't it have more points?
The **moment equation inside** (eq 1) becomes (substituting $b''$ and v'') 
$$
\begin{align}
&\gamma v'' \simeq  ik (B_{0x}b'') \\[.8em]
\implies&- \frac{\gamma v\left( \frac{\delta}{2} \right)}{\delta^2} \simeq ikB_{0x} \left( \frac{\delta}{2} \right)\cdot \frac{\Delta' \cdot b\left( \frac{\delta}{2} \right)}{a \delta}
\end{align}
$$
The **magnetic field equation outside** (eq 4) becomes 
$$
\begin{align}
&\gamma b \simeq ik B_{0x} v \\[.8em]
\implies&v \simeq \frac{\gamma b}{ikB_{0x}} = -\frac{i\gamma b}{kB_{0x}}
\end{align}
$$
We need to match the solution inside and outside at $\delta /2$, so we substitute (eq 4) into (eq 1)
$$
\begin{align}
& - \frac{\gamma}{\delta^\cancel{ 2 }} \frac{\cancel{ i }\gamma \cancel{ b\left( \frac{\delta}{2} \right) }}{kB_{0x} \left( \frac{\delta}{2} \right)} = \cancel{ i }k B_{0x} \left( \frac{\delta}{2} \right) \frac{\cancel{ b\left( \frac{\delta}{2} \right) }}{a \cancel{ \delta }} \Delta' \\[.8em]
 \implies&  \gamma ^2 \simeq \left[ k B_{0x}^2\left( \frac{\delta}{2} \right) \right] ^2\left( \frac{\delta}{a} \right) \Delta' 
\end{align}
$$
Using Taylor we get (for $B_{0x}$)
$$
 B_{0x} \left( \frac{\delta}{2} \right) \simeq \cancel{ B_{0x}(0) } + \frac{\delta}{2} B_{0x}' (0)
$$
and substituting (don't confuse $\delta /2$ with $\delta /a$) (recall $\bar{B} = B_{0x} (y) \hat{x} + \bar{b}_{1}$)
$$
\begin{align}
 \gamma ^2 &\simeq \left[ k \left( \frac{\delta}{2} \right) B_{0x}'^2\right] ^2\left( \frac{\delta}{a} \right) \Delta'  = \\[.8em]
&= k^2 B_{0}^2 \left( \frac{aB_{0x}'}{2B_{0x}} \right) ^2 \left(  \frac{\delta}{a} \right) ^3 \Delta ' = \\[.8em]
&= k^2 B_{0}^2 A \left(  \frac{\delta}{a} \right) ^3 \Delta ' 
\end{align}
$$
with ($B_{0x} \to + \infty$)
$$
 A \equiv \left[ \frac{aB_{0x}'}{2B_{0x}}  \right] ^2  
$$
$\gamma > 0$ and  $\gamma \in \mathbb{R}$.
From the magnetic field equation inside (eq 2) we isolate the term $\delta /a$ as follow 
$$
\begin{align}
 &\gamma b \simeq \eta b''&& \implies &&\gamma \cancel{ b } \simeq \eta\frac{\Delta'\cancel{ b }}{a \delta}  \\[.8em]
\implies &\gamma = \frac{\eta\Delta'}{a\delta} &&\implies&& \frac{\delta}{a} = \frac{\eta\Delta'}{a^2 \gamma}
\end{align}
$$
we substitute and we get 
$$
\begin{align}
\gamma ^2 \simeq k^2 B_{0}^2 A \left(  \frac{\eta\Delta'}{a^2 \gamma} \right) ^3 \Delta '  &&\implies&& \gamma  \simeq k^{2/5} B_{0}^{2/5} A^{1/5} \frac{\eta^{3/5}}{a^{6/5}} \Delta '^{4/5}
\end{align}
$$
so 
HERE $S$ should also depend on $A$ right?
$$
 \gamma \sim k ^{2/5} S^{-3/5} \Delta' ^{4/5}
$$
with the Lundquist number 
$$
S=  \frac{aB_{0}}{\eta}
$$
$\Delta'$ is a parameter which depends on $k$ 
$$
 \gamma \simeq S^{-3/5} f(k)
$$
$f(k)$ is found numerically
