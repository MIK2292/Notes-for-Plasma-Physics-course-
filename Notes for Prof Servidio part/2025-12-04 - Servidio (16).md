# Force free equilibria in cartesian geometry
Recall $\nabla \times \bar{B} = \mu \bar{B}$.
2.5D, fields depend on $x$ and $y$, but they can have an out-of-plane component 
(eg. fields can have $A_{z}(x,y)$)
So we have
$$
\begin{align}
 \partial_{z} = 0, && \bar{A} = [A_{x}(x,y), A_{y}(x,y), A_{z}(x,y)]
\end{align}
$$
We work in $x-y$ plane
We use the Helmoltz decomposition (for solenoidal field)
$$
\begin{align}
 \bar{B} = \nabla \Psi \times \hat{z} +  B_{z} \hat{z} && \text{and} && \bar{B}_{\text{planar}} = \nabla \Psi \times \hat{z} =  \begin{cases}
B_{x} = \partial_{y} \Psi \\[.6em]
B_{y} = - \partial_{x} \Psi 
\end{cases} 
\end{align}
$$
and
$$
\nabla \times \bar{a} = \nabla \times (\Psi \hat{z} ) = \nabla \Psi \times \hat{z}
$$
so with this we work from
$$
(B_{x} ,B_{y} ,B_{z}) \ \ \to \ \  (\Psi ,B_{z})
$$
we find $J_{z}$ as ($\Psi  = \Psi (x,y)$)
$$
\begin{align}

J_{z} = \nabla \times \bar{B}_{\text{planar}} = - \nabla ^2 \Psi
\end{align}
$$
so
$$
\begin{align}
 \mu \bar{B} &= \nabla \times \bar{B} =  \\[.8em]
&=\nabla \times (\nabla \Psi \times \hat{z} ) + \nabla \times (B_{z} \hat{z}) = \\[.8em]
&= - \nabla^2 \Psi \hat{z} +\nabla \times (B_{z} \hat{z})
\end{align}
$$
and
$$
 \begin{cases}
\mu B_{x} = \partial _{y} B_{z} \\[.6em]
\mu B_{y} = - \partial_{x} B_{z}  \\[.6em]
\mu B_{z} = - \nabla ^ 2 \Psi 
\end{cases}
$$
we rewrite this using the derivatives of $\Psi$ 
$$
  \begin{cases}
\mu \partial_{y} \Psi = \partial _{y} B_{z} \\[.6em]
-\mu  \partial_{x} \Psi = - \partial_{x} B_{z}  \\[.6em]
\mu B_{z} = - \nabla ^ 2 \Psi 
\end{cases}
$$
from the first two we have
$$
\begin{align}
\begin{cases}
\partial_{y} \left( \mu \Psi - B_{z} \right) = 0 \\[.8em]
\partial_{x} \left( \mu \Psi - B_{z} \right) = 0
\end{cases} 
&&\implies&& B_{z} = \mu \Psi
\end{align}
$$
combining this with the third 
$$
 \nabla^2 \Psi + \mu ^2 \Psi = 0
$$
which is known as **Helmoltz equation**.

We solve it 
$$
 \frac{ \partial^2 \Psi }{ \partial x^2 }  + \frac{ \partial^2 \Psi }{ \partial y^2 } + \mu^2 \Psi = 0
$$
Periodic boundaries (Fourier decomposition only on $x$) 
$$
 \Psi (x,y) = \sum_{l} \tilde{\Psi} (l,y) e^{ ilx }
 $$
 so the Helmholtz equation becomes 
$$
 \sum_{l} (-l^2 \tilde{\Psi} e^{ ilx } ) + \sum_{l} \frac{ \partial^2 \tilde{\Psi} }{ \partial y^2 } e^{ ilx } + \sum_{l} \mu^2 \tilde{\Psi} e^{ ilx } = 0
$$
we multiply by $e^{ -ikx }$ in order to eliminate the sum and focus on one wavenumber at a time
(we could use the orthogonality of the base and avoid this passage)
$$
\begin{align}
 &\sum_{l} (-l^2 \tilde{\Psi}(l,y) e^{ i(l-k)x } ) + \sum_{l} \frac{ \partial^2 \tilde{\Psi} (l,y) }{ \partial y^2 } e^{ i(l-k)x } + \sum_{l} \mu^2 \tilde{\Psi}(l,y) e^{ i(l-k)x } = 0 \\[.8em]
\implies&  \sum_{l} (-l^2 \tilde{\Psi}(l,y) \delta_{l,k} ) + \sum_{l} \frac{ \partial^2 \tilde{\Psi} (l,y) }{ \partial y^2 } \delta_{l,k} + \sum_{l} \mu^2 \tilde{\Psi}(l,y) \delta_{l,k} = 0  \\[.8em]
\implies&  -k^2 \tilde{\Psi}(k,y)  +  \frac{ \partial^2 \tilde{\Psi} (k,y) }{ \partial y^2 }  + \mu^2 \tilde{\Psi}(k,y) = 0
\end{align}
$$
so
$$
\frac{ \partial^2 \tilde{\Psi} (k,y) }{ \partial y^2 } + (\mu^2 - k^2) \tilde{\Psi}(k,y) = 0
$$
At infinity we don't have magnetic field and at $y=0$ we have a finite magnetic field 
$$
\begin{align}
\tilde{\Psi}(k,y) \stackrel{y \to + \infty}\longrightarrow 0 ;&&\tilde{\Psi}(k,y=0) = \tilde{\Psi}_{0}(k) 
\end{align}
$$
On large scales (small vorteces die first) we have only $k_{0}$. 
Using only $k_{0}$ and using the previous boundary condition we have the following solution (procedure left as exercse)
$$
 \Psi (x,y) = e^{ -y\sqrt{ k_{0}^2 - \mu^2 } } \cos (k_{0}x)
$$
We verify that it's a solution
$$
\begin{align}
 \frac{ \partial^2 \Psi }{ \partial x^2 }  +& \frac{ \partial^2 \Psi }{ \partial y^2 } + \mu^2 \Psi = -k_{0} ^2 e^{ -y\sqrt{ k_{0}^2 - \mu^2 } } \cos (k_{0}x) + \\[.6em]
&+ (k_{0}^2-\mu^2) e^{ -y\sqrt{ k_{0}^2 - \mu^2 } } \cos (k_{0}x) + \mu^2e^{ -y\sqrt{ k_{0}^2 - \mu^2 } } \cos (k_{0}x) = 0
\end{align} 
$$
We plot it
$$
 x \in [0,2\pi] = [0,L_{0}] \implies k = 1 =\frac{2\pi}{L_{0}}
$$
$$
 \mu = \frac{1}{\sqrt{ 2 }}
$$
(isolines, continuous -> positive, dashed -> negative)

$$

# Bidimensional MHD
We start from
$$
 \begin{cases}
\displaystyle \frac{ \partial \bar{U} }{ \partial t } = - \bar{U} \cdot \nabla \bar{U} - \nabla P + \bar{B} \cdot \nabla \bar{B} + \nu \nabla ^2 \bar{U} \\[.6em]
\displaystyle\frac{ \partial \bar{B} }{ \partial t } = \nabla \times [\bar{U} \times \bar{B} - \eta \nabla \times \bar{B}]
\end{cases}
$$
HERE where does $\bar{B} \cdot \nabla \bar{B}$ come from?
We assume 
$$
\begin{align}
 \nu = 0,&& \eta = 0, &&\bar{U} = 0
\end{align}
$$
so
$$
 \begin{cases}
\displaystyle \frac{ \partial \bar{U} }{ \partial t } = - \nabla P + \bar{B} \cdot \nabla \bar{B}  \\[.6em]
\displaystyle\frac{ \partial \bar{B} }{ \partial t } = 0
\end{cases}
$$
we apply the curl to the first equation and we take out the curl in the second ($\bar{B} = \nabla \Psi \times \hat{z}$)
(the pressure term vanish bcause the rotor of a gradient is null)
HERE how do we get the following eq? can derivatives enter other derivatives with no correction? 
$$
 \begin{cases}
\displaystyle0 =  \bar{B} \cdot \nabla j_{z}  \\[.8em]
\displaystyle\frac{ \partial \Psi }{ \partial t } = 0
\end{cases}
$$

The full equation would be the following, but we don't need for this calculation
$$
 \begin{cases}
\displaystyle\frac{ \partial \omega_{z} }{ \partial t } = - \bar{U} \cdot \nabla \omega_{z} + \bar{B} \cdot \nabla j_{z} + \nu \nabla^2 \bar{\omega} \\[.8em]
\displaystyle\frac{ \partial \Psi }{ \partial t } = - \bar{U} \cdot \nabla \Psi + \eta \nabla ^2 \Psi
\end{cases}
$$

We now continue from 
$$
 \bar{B} \cdot \nabla j_{z}  = 0
$$
we recall that 
$$
\begin{align}
 \bar{B} = \nabla \Psi \times \hat{z},&& j_{z} = - \nabla^2 \Psi
\end{align}
$$
after we substitute we get 
$$
 (\nabla \Psi \times \hat{z}) \cdot \nabla (\nabla^2 \Psi) = 0
$$
expandind the scalar product
$$
 - \partial _{y} \Psi \cdot  \partial_{x} (\nabla^2 \Psi) + \partial _{x} \Psi \cdot  \partial_{y} (\nabla^2 \Psi) = 0
$$
We choose $j_{z}$ as a function of $\Psi$: $j_{z} = f(\Psi )$. We can do this because it's compatible with the condition $j_{z} = - \nabla^2 \Psi$. Then we get
$$
\begin{align}
  &- \partial _{y} \Psi \cdot  \partial_{x} ( f(\Psi )) + \partial _{x} \Psi \cdot  \partial_{y} ( f(\Psi )) = 0 \\[.8em]
\implies& - \partial _{y} \Psi \cdot \frac{ \partial f }{ \partial \Psi } \cdot  \partial_{x} \Psi + \partial _{x} \Psi \cdot \frac{ \partial f }{ \partial \Psi } \cdot \partial_{y} \Psi = 0  \\[.8em]
\implies&  \frac{ \partial f }{ \partial \Psi }[- \partial _{y} \Psi  \cdot  \partial_{x} \Psi + \partial _{x} \Psi \cdot \partial_{y} \Psi] = 0
\end{align}
$$
so we go from a wide class of function to a narrower.
we restrict again by using force free
$$
\begin{align}
 j_{z} = f(\Psi) = \mu^2 \Psi &&\implies &&  \nabla ^2 \Psi + \mu^2 \Psi = 0
\end{align}
$$
another interesting restriction is 
$$
\begin{align}
 j_{z} = f (\Psi) = e^{ \alpha \Psi } &&\implies&& \nabla^2 \Psi + \alpha e^{ \beta \Psi } = 0 
\end{align}
$$
which is very realistic in plasma
One famous solution is 
$$
\begin{align}
 j_{z} (x) = \frac{2\alpha^2}{\cosh^2 \alpha x} && \implies && B_{y } =  2 \alpha  \tanh \alpha x
\end{align}
$$

Ins the system we have 
$$
 \begin{align}
&\bar{B}_{0} = B_{0x} (y) \hat{x} = B_{0} \tanh \left( \frac{y}{a} \right) \hat{x}  \\[.6em]
 &\bar{J}_{0} = J_{0} (y) \hat{z} = - \partial _{y} B_{0x}\simeq - \frac{1}{\cosh^2\left( \frac{y}{a} \right)}\hat{z}
\end{align}
$$
PIC b0x j0y
![[IMG_20251204_121729109_HDR~2.jpg|300]]
current sheet -> curr = derivative of B
The current sheet is the sheet close to $y=0$, of thickness $\delta$. Here $J_{0} \neq 0$ 

$a$ typical lenght of magnetic field flip
$L$ typical size of system (large)
$\delta$ typical thickness of current sheet
$$
\delta \ll a \ll L
$$
We perturb the system with incompressible fluctuations
$$
\begin{cases}
 \bar{v}_{1} = v_{x} (x,y,t) \hat{x} + v_{y} (x,y,t) \hat{y} 
 \\[.8em]
\bar{b}_{1} = b_{x} (x,y,t) \hat{x} + b_{y} (x,y,t) \hat{y} 
\end{cases}
$$
with 
$$
\begin{align}
 \lvert \bar{v}_{1} \rvert, \lvert \bar{b}_{1} \rvert \to 0  
, && \nu = 0, && \eta \neq 0
\end{align}
$$
so we have a real plasma with resistivity
$$
\begin{cases}
 \dfrac{ \partial \bar{V}_{1} }{ \partial t } = -\cancel{ \bar{V}_{1} \cdot \nabla \bar{V}_{1}  } - \nabla P_{1} + \bar{J}_{0}\times \bar{b}_{1} + \bar{J}_{1} \times \bar{b}_{0} + \cancel{ \bar{J}_{0}\times \bar{b}_{0} } + \cancel{ \bar{J}_{1} \times \bar{b}_{1} } \\[.8em]
\dfrac{ \partial \bar{b}_{1} }{ \partial t } = \nabla \times ( \bar{V}_{1} \times \bar{B}_{0}) + \cancel{ \nabla \times (\bar{V}_{1} \times \bar{b}_{1}) } + \eta \nabla^2 \bar{b}_{1}
\end{cases}
$$
which gets simplified to 
$$
\begin{cases}
 \dfrac{ \partial \bar{V}_{1} }{ \partial t } =  - \nabla P_{1} + \bar{J}_{0}\times \bar{b}_{1} + \bar{J}_{1} \times \bar{b}_{0} \\[.8em]
\dfrac{ \partial \bar{b}_{1} }{ \partial t } = \nabla \times ( \bar{V}_{1} \times \bar{B}_{0}) + \eta \nabla^2 \bar{b}_{1} \\[.8em]
\nabla \cdot \bar{V}_{1} = \nabla \cdot \bar{b}_{1} = 0
\end{cases}
$$
Hypotesys (valid only in the very first stage, before nonlinearity)
$$
 \begin{cases}
\bar{V}_{1} = \bar{V} (y) e^{ \gamma t + ikx } \\[.6em]
\bar{b}_{1} = \bar{b}(y) e^{ \gamma t + ikx }
\end{cases}
$$
we want to find the $\gamma$ 
we use the notation $\partial _y f = f'$ 
$$
\begin{align}
 \nabla \cdot \bar{b}_{1} = 0 &&\implies&& ikb_{x}(y) e^{ \gamma t + ikx } + b'_{y}(y) e^{ \gamma t + ikx } = 0
\end{align}
$$
so 
$$
 b_{x}(y) = i \frac{b'_{y}(y)}{k}
$$
and, following the same reasoning
$$
\begin{align}
 \nabla \cdot \bar{v} _{1} = 0 &&\implies&&  v_{x}(y) = i \frac{v'_{y}(y)}{k}
\end{align}
$$
now we take the curl of the first equation to get rid of the pressure
$$
 \frac{ \partial \nabla \times \bar{v}_{1} }{ \partial t } = \nabla \times [\bar{J}_{0}\times \bar{b}_{1} + \bar{J}_{1} \times \bar{B}_{0}]
$$
and we only consider the $\hat{z}$ component.
considering also 
$$
 \bar{J}_{0} = J_{0}\hat{z} = - \partial _{y} B_{0x} \hat{z} = -B_{0x}' \hat{z}
$$
$$
 \bar{J}_{0}\times \bar{b}_{1} + \bar{J}_{1} \times \bar{B}_{0} = \begin{pmatrix}
b_{y}B_{0x}' \\
-b_{x}B_{0x}' + B_{0x} [\partial_{x} b_{y} - \partial_{y} b_{x}] \\
0
\end{pmatrix}
$$
we need to evaluate the rotor of it
and we get  (recall $b_{x}(y) = \frac{i}{k} b'_{y}(y)$)
$$
\begin{align}
  \frac{ \partial \nabla \times \bar{v}_{1} }{ \partial t } \cdot \hat{z} &= \nabla \times [\bar{J}_{0}\times \bar{b}_{1} + \bar{J}_{1} \times \bar{B}_{0}] \cdot \hat{z} = \\[.8em]
&= \partial_{x} [-b_{x}B_{0x}' + B_{0x} (\partial_{x} b_{y} - \partial_{y} b_{x})] - \partial_{y} [b_{y} B_{0x}']   =  \\[.8em]
&= \left\{ \cancel{ -ikb_{x} B_{0x}' } - B_{0x}b_{y}k^2 - b_{x}' ik B_{0x} \cancel{ - b_{y}'B_{0x}' } - b_{y} B_{0x}'' \right\} e^{ \gamma t + ikx }\\[.8em]
&= \left\{- B_{0x}b_{y}k^2 - b_{x}' ik B_{0x} - b_{y} B_{0x}'' \right\} e^{ \gamma t + ikx } = \\[.8em]
&= \left\{ B_{0x}( - b_{x}' ik - b_{y}k^2) - b_{y} B_{0x}'' \right\} e^{ \gamma t + ikx } = \\[.8em]
&= \left\{ B_{0x}(b_{y}'' - k^2 b_{y}) - b_{y} B_{0x}'' \right\} e^{ \gamma t + ikx }
\end{align}
$$
the LHS is (recall $v_{x}(y) = \frac{i}{k} v'_{y}(y)$)
$$
 \begin{align}
\frac{ \partial \nabla \times \bar{v}_{1} }{ \partial t } \cdot \hat{z} &=  \frac{ \partial  }{ \partial t } \left\{ \partial_{x} [V_{y}(y)e^{ \gamma t + ikx }] - \partial_{y} [V_{x}(y)e^{ \gamma t + ikx }] \right\} = \\[.8em]
&= \frac{ \partial  }{ \partial t } \left\{ [ikV_{y} - V_{x}'] e^{ \gamma t + ikx }  \right\} = \\[.8em]
&= \gamma \left( ikV_{y} - \frac{i}{k} V_{y}'' \right) e^{ \gamma t + ikx }   = \\[.8em]
&= -\frac{i\gamma}{k} \left(V_{y}'' - k^2 V_{y}\right) e^{ \gamma t + ikx } 
\end{align}
$$
and combining them we have
$$
\begin{align}
-\frac{i\gamma}{k} \left(V_{y}'' - k^2 V_{y}\right)= B_{0x}(b_{y}'' - k^2 b_{y}) - b_{y} B_{0x}''
\end{align}
$$
so ($-i = i^{-1}$) 
$$
 \begin{align}
 \gamma (V_{y}'' - k^2 V_{y}) = i k [B_{0x} (b_{y}k^2 - ik b_{x}') - b_{y} B_{0x}'']
\end{align}
$$

\end{cases}
$$
