# Sweet-Parker model for magnetic reconnection
One of the first model to explain magnetic reconnection
Change of topology
Converts magnetic energy to kinetic energy and heat
1956 Peter Sweet was giving a speech in USA explaining Giovannelli picture of 2 flux tube which create a narrow layer (he was saying "I am working on this before publishig it") and parker (who listened to him) went home and published before Sweet.
Articles:
E.N.Parker, JGR 62, 509, 1957
P.A. Sweet, IAU Symposium 6, 123, 1958

Incompressible, resistive MHD
Similar case to 2 flux tube, before we had a line of points with zero magnetic field.
Now we study the case with only one point with zero magnetic field.

$U_{in}, B_{in}$ is above/below (upstream)

Hypothesis
- Mirror symmetry
- $U_{in}\ll B_{in}$ 
- $B_{out} \sim 0$ 
- It is very dinamical, however it is steady state (the picture does not change) $\partial / \partial t=0$ 
- Incompressible
- bidimensional
- Resistivity $\eta$ is localized
- we neglect viscosity ($\nu = 0$) 
On the lower and upper side, the $U$ and $B$ only have one component 
$$
\begin{align}
U_{in} = U_{in} \hat{y} , &&B_{in} = B_{in} \hat{x}
\end{align}
$$
On the left and right regions we assume, similarly,
$$
\begin{align}
U_{out} = U_{out} \hat{x}  ,&&B_{out} \sim 0
\end{align}
$$

The important parameters are
$$
 \begin{align}
\bar{U}_{in}= \pm U_{in} \hat{y}  ;&&
\bar{B}_{in}= \pm B_{in} \hat{x} ;&& \bar{U}_{out}= \pm U_{out} \hat{x}
\end{align}
$$
and $\eta,\delta,L$.
We will look at the reconnection rate $U_{in}/U_{out}$ 

The equations are
HERE where does $\bar{B} \cdot \nabla \bar{B}$ come from?
$$
 \begin{align}
&\nabla \cdot \bar{U} = \nabla \cdot \bar{B} = 0 \\[.8em]
&\frac{ \partial \bar{U} }{ \partial t } = \bar{U} \times \bar{\omega} - \nabla \left( P + \frac{U^2}{2} +\frac{B^2}{2} \right) + \bar{B} \cdot \nabla \bar{B} \\[.8em]
&\frac{ \partial \bar{B} }{ \partial t } = - \nabla \times \bar{E} = \nabla \times \left[ \bar{U} \times \bar{B} - \eta \bar{J} \right] 
\end{align}
$$
We integrate MHD over the black box ($V = 2L \cdot 2\delta$)
$$
 \int_{V} \nabla \cdot \bar{U} \, d^2x = 0
$$
and with $\hat{n}$ outside normal with respect to the box, we have
$$
 \int_{V} \nabla \cdot \bar{U} \, d^2x =  \oint \bar{U} \cdot \hat{n} \, d \ell = \underbrace{ - U_{in} 2L }_{ \text{below} }  \underbrace{ +U_{out} 2\delta }_{ \text{left} } \underbrace{ - U_{in} 2L }_{ \text{above} }  \underbrace{ +U_{out} 2\delta }_{ \text{right} } = 0
$$
where we used the divergence theorem.
PIC box n
![[IMG_20251212_102923336_HDR~2.jpg|350]]

The first law is the **conservation of mass**, which reads
$$
 U_{in} L = U_{out} \delta
$$
this is why $U_{out}\gg U_{in}$.

The second law (**conservation of electric field in space**) is derived as follows
$$
\begin{align}
 0= \frac{ \partial \bar{B} }{ \partial t } = - \nabla \times \bar{E}  
\end{align}
$$
So when we move in space, the electric field is conservative.
We take $\bar{E}$ along $z$ because $\bar{U}$ and $\bar{B}$ live in the 2D plane. 
$$
 \bar{E} = - \bar{U} \times \bar{B} + \eta \bar{J} = E_{z} \hat{z}
$$
$$
\begin{align}
 \nabla \times (E_{z} \hat{z} )  = 0 &&\implies&& \partial_{y} E_{z} = \partial_{y}  \left[ -\bar{U} \times \bar{B} + \eta \bar{J} \right]   = 0
\end{align}
$$
which is the second law.

**Third law** 
We want to move from the central-lower part of the box to the $X$ point.  
PIC move in the box 
![[IMG_20251212_104549875_HDR~2.jpg|350]]
From last formula, we get
$$
\begin{align}
 E_{1} = E_{2} &&\implies&& E_{in} = E_{X}
\end{align}
$$
we say that (we neglect $J$ at the border and $B=0$ in the $X$ point)
$$
\begin{align}
\begin{cases}
E_{in} = - \bar{U}_{in} \times \bar{B}_{in} + \cancel{ \eta \bar{J}_{in} } \\[.8em]
E_{X} = - \cancel{ \bar{U}_{X} \times \bar{B}_{X} } + \eta \bar{J}_{X}
\end{cases}
\end{align}
$$
so
HERE missing minus sign
$$
\begin{align}
\begin{cases}
E_{in} = U_{in}B_{in} \\[.8em]
 E_{X } = \eta J_{X }
\end{cases}
&&\implies&& U_{in } B_{in} = E_{in} = E_{X} =  \eta J_{X }
\end{align}
$$
For $J_{X}$, we use the rotor of $\bar{B}$ 
$$
\begin{align}
&J_{X } =[\nabla \times \bar{B}]_{z}\simeq \frac{B_{in}- (-B_{in})}{2\delta} = \frac{\cancel{ 2 }B_{in}}{\cancel{ 2 } \delta} = \frac{B_{in}}{\delta}
\end{align}
$$
substituting it we have
$$
 \begin{align}
U_{in} B_{in} = \eta J_{X } = \eta\dfrac{B_{in}}{\delta}
 &&\implies&& U_{in } = \frac{\eta}{ \delta}
\end{align}
$$
which is the third law.

Now we move from the $X$ point to the right 
PIC formica 
![[IMG_20251212_105243872_HDR~2.jpg|400]]
We use stationarity
$$
 \frac{ \partial \bar{U} }{ \partial t } = 0
$$
Moving from 1 to 2 we had
$$
0 = \frac{ \partial U_{y} }{ \partial t }  = \left( \bar{U} \times \bar{\omega} \right) \cdot \hat{y} - \partial_{y} \left[ P+\frac{U^2}{2} +\frac{B^2}{2} \right] + \bar{B} \cdot \nabla B_{y} 
$$
The first term is null because
$$
\begin{align}
 \bar{U} = U_{in} \hat{y},&& \bar{\omega} = \omega \hat{z}
\end{align}
$$
The last term is null because 
$$
 \begin{align}
\bar{B}_{in} = B_{in} \hat{x} &&\implies && B_{y}= 0
\end{align}
$$
So it must be 
$$
\partial_{y} \left[ P+\frac{U^2}{2} +\frac{B^2}{2} \right]  = 0
$$
Now we have the **bernoulli equation for MHD** 
$$
P+\frac{U^2}{2} +\frac{B^2}{2} = \text{constant}
$$

Moving from $2$ to $3$ ($\bar{U} = U_{out} \hat{x},\ \ \  \bar{\omega} = \omega \hat{y}, \ \ \ \bar{B}_{out} \sim 0$)
$$
\begin{align}
 \frac{ \partial U_{x} }{ \partial t } = 0 &&\implies&& \partial_{x} \left( P+ \frac{U^2}{2} + \frac{B^2}{2} \right) = 0

\end{align}$$
so this is valid everywhere
$$
P+\frac{U^2}{2} +\frac{B^2}{2} = \text{constant}
$$
in particular
$$
 P_{in}+\cancel{ \frac{U_{in}^2}{2} } +\frac{B_{in}^2}{2} = P_{X }+\cancel{ \frac{U_{X }^2}{2} } +\cancel{ \frac{B_{X }^2}{2} }
$$
we cancel $B_{X}^2$ because it's null by definition and $U_{X}^2$ because it's stagnant. 
We also stay in the hypotesis that $B_{in} \gg U_{in}$.
So the remaining terms yeld
$$
 P_{X } = P_{in}+ \frac{B_{in}^2}{2}
$$
Another interesting case (considering $B_{out} \sim 0$) is 
$$
 P_{X } = P_{out} + \frac{U_{out}^2}{2} + \cancel{ \frac{B_{out}^2}{2} } = P_{out} + \frac{U_{out}^2}{2}
$$
Comparing the last two results, we have
$$
P_{in} + \frac{B_{in}^2}{2 } = P_{out} + \frac{U_{out}^2}{2}
$$
We say that pressure is constant because gradient of pressure drifts away, so finally
$$
 \frac{B_{in}^2}{2} = \frac{U_{out}^2}{2}
$$
which in Alvfènic notation (and units)
$$
 B_{in} = U_{out} = U_{A}
$$
which is the again third law (bernoulli theorem).

**Summary**
So to sum up 
$$
 \begin{cases}
  U_{in} L = U_{out} \delta &&\text{1st law}\\[.8em]
U_{in }= \dfrac{\eta}{\delta} &&\text{2nd law}\\[.8em]
U_{out  } = U_{A}&&\text{3rd law}
\end{cases}
$$
From the first law we have
$$
\begin{align}
 \frac{U_{in}}{U_{out} } = \frac{\delta}{L} &&\implies&&  \delta = L \frac{U_{in}}{U_{out}}
\end{align}
$$
From the second and third law, we obtain
$$
 \frac{U_{in}}{U_{out}} = \frac{\eta}{\delta } \frac{1}{U_{A}} = \frac{\eta}{\delta U_{A}}
$$
so, using again the first law to substitute the $\delta$, we get
$$
\begin{align}
 \frac{U_{in}}{U_{out} } = \frac{\eta U_{out}}{U_{in} L U_{A}} = \frac{U_{out}}{U_{in}} \frac{\eta}{LU_{A}}&& \implies&& \frac{U_{in}}{U_{out}} = \sqrt{ \frac{\eta}{U_{A}L}  } \equiv S^{-1/2}

\end{align}$$

We define the reconnecting flux as 
$$
 \Psi = \int_{P_{0}}^{P_{X }} \bar{B} \cdot \hat{n} \, d \ell
$$
PIC reconn flux
![[IMG_20251212_111245831_HDR~2.jpg|300]]
with 
HERE ricontrolla tutto
$$
\begin{align}
 \bar{B} = \nabla \bar{a} \times \hat{z} &&\implies&& \Psi = a_{X } - a_{0}
\end{align}
$$
We evaluate the time derivative of the reconnecting flux
$$
 \frac{d}{dt}  \Psi = \frac{d}{dt}  a_{X } - \frac{d}{dt}  a_{0 } = \eta J_{X } - \cancel{ \eta J_{0} }
$$
$$
 \frac{d}{dt}  \Psi = \eta J_{X  } = \frac{\eta U_{A}}{\delta} = \eta \frac{ U_{A}}{L} \frac{U_{out}}{U_{in} } = \eta \frac{ U_{A}}{L} \sqrt{ \frac{U_{A}L}{\eta}  } 
$$
so
$$
 \dot{\Psi} = \sqrt{ \frac{\eta U_{A}^3}{L} }
$$

# Harris current sheeth (kinetic)
1962
Can we describe a tangential equilibrium in terms of full kinetic theory?
We consider a gradient along $x$: $\nabla = \partial _x \hat{x}$ 
PIC xyz 
![[IMG_20251212_113225692~2.jpg|300]]
Consider the full Vlasov plasma with no collisions, made up by two species ($\alpha=i,e$)
$$
\begin{align}
 q_{i} = -q_{e} = e; &&
n_{i} \simeq n_{e} \equiv n
\end{align}
$$
We assume stationarity, translational symmetry and non-zero velocities (so we have a current)
$$
\begin{align}
 \frac{ \partial  }{ \partial t } = 0 ;&&  \partial_{y} = \partial_{z} = 0;&& U_{i} \neq 0 ; && U_{e} \neq 0
\end{align}
$$
We consider Vlasov for ions and electrons ($\alpha = i,e$)
$$
 \frac{ \partial f_{\alpha} }{ \partial t } + \bar{v} \cdot \nabla f_{\alpha} + \frac{e}{m_{e}} \left[ \bar{E} + \frac{\bar{V}\times \bar{B}}{c} \right]  \cdot \nabla_{\bar{v}} f_{\alpha} = 0 
$$
which is coupled with Maxwell equations
$$
\begin{cases}
 \displaystyle\nabla \cdot \bar{E}  = 4\pi \rho_{tot}\\[.8em]
  \displaystyle\nabla \times \bar{E} = - \frac{1}{c} \frac{ \partial \bar{B} }{ \partial t }  \\[.8em]
\nabla \cdot \bar{B} = 0 \\[.8em]
\displaystyle \nabla \times \bar{B}  = \frac{4\pi}{c} \bar{J} + \frac{1}{c} \frac{ \partial \bar{E} }{ \partial t } 
\end{cases}
$$
In stationarity conditions ($\partial  / \partial t = 0$), Maxwell equations gets reduced to 
$$
 \begin{cases}
 \displaystyle\nabla \cdot \bar{E} = 4\pi \rho_{tot}= 4\pi e \left[ n_{i}+n_{e} \right]  \\[.8em]
\displaystyle\nabla \times \bar{B}  = \frac{4\pi}{c} \bar{J}  = \frac{4\pi}{c} \left[ e n_{i} \bar{U}_{i} - e n_{e} \bar{U}_{e}  \right] 
\end{cases}
$$
or, written in terms of the distribution function
$$
 \begin{cases}
 \displaystyle\nabla \cdot \bar{E} = 4\pi e \left[ \int f_{i} \, d^3v  -  \int f_{e} \, d^3v  \right]  \\[.8em]
\displaystyle\nabla \times \bar{B}  = \frac{4\pi}{c} e\left[ \int \bar{v}f_{i} \, d^3v  -  \int \bar{v}f_{e} \, d^3v   \right]  
\end{cases}
$$
with $f_{\alpha} (x,v_{x},v_{y},v_{z})$ discontinuous.
Other supporting equations are (using $\partial_{y} = \partial_{z} = 0$)
$$
\begin{align}
\bar{B} = \nabla \times \bar{A} = \frac{ \partial A_{y} }{ \partial x } \cdot \hat{z}  &&\implies && \nabla \times \bar{B} = -\frac{ \partial ^2A_{y} }{ \partial x^2 } \cdot \hat{y}
\end{align}
$$
and
$$
 \begin{align}
 \nabla \times \bar{E} = \frac{ \partial \bar{B} }{ \partial t } = 0 &&\implies&& \bar{E} = - \nabla \phi  &&\implies&& \nabla \cdot \bar{E} = -\nabla^2 \phi = -\frac{ \partial^2 \phi }{ \partial x^2 }
\end{align}
$$
so these two equations become the Poisson equation for the electric potential and a simplified equation to find the vector potential 
(we multiply $\nabla \times \bar{B}$ by $\hat{y}$ because other components are null)
$$
 \begin{cases}
\displaystyle \frac{ \partial^2 \phi }{ \partial x^2 }  = -4\pi e \left[ \int f_{i} \, d^3v  -  \int f_{e} \, d^3v  \right] \\[0.8em]
\displaystyle\frac{ \partial ^2A_{y} }{ \partial x^2 }  = -\frac{4\pi}{c} e\left[ \int \bar{v}f_{i} \, d^3v  -  \int \bar{v}f_{e} \, d^3v   \right] \cdot \hat{y} 
\end{cases}
$$
