From the 2 fluids equations
$$
 \begin{cases}
\displaystyle \frac{ \partial n_{\alpha} }{ \partial t } + \nabla \cdot  \left( n_{\alpha} \bar{U}_{\alpha} \right) = 0 && (A)\\[.8em]
\displaystyle \frac{ \partial m_{\alpha}n_{\alpha}\bar{U}_{\alpha} }{ \partial t } + \nabla \cdot \left(  m_{\alpha} n_{\alpha} \bar{U}_{\alpha} \bar{U}_{\alpha}  \right) + \nabla P^\alpha - q_{\alpha} n_{\alpha} \left[ \bar{E} + \bar{v}\times \bar{B} \right] = 0  && (B) \\[.8em]
P^\alpha = An_{\alpha}^\gamma  && (C) \\[.8em]
\displaystyle \nabla \cdot \bar{E} = \frac{1}{\varepsilon_{0}} \sum_{\alpha} q_{\alpha} n_{1} &&(D) \\[.8em]
 \dfrac{ \partial \bar{B}  }{ \partial t } = - \nabla \times \bar{E} &&(E) \\[.8em]
 \displaystyle\nabla \times \bar{B} = \mu_{0} \bar{J} + \mu_{0}\varepsilon_{0} \frac{ \partial \bar{E} }{ \partial t } &&(F) \\[.8em]
\nabla \cdot \bar{B} = 0&& (G)
\end{cases}
$$
We want a simpler version of this system

# Compressible Magnetohydrodynamics (MHD)
Protons in a magnetic field rotate at their proto-cyclotron frequency 
$$
 \omega_{cp} = \frac{eB}{m_{p}c} 
$$
Eg. solar coronal loops can be studied at the scale of hours or days. 
We have
$$
 \omega \ll \omega_{cp}
$$
The ion skin depth is
$$
\begin{align}
 d_{p} = \frac{c}{\omega_{p}}
, && \omega_{p} = \sqrt{ \frac{n_{p}e^2}{m_{p}\varepsilon_{0}} }
\end{align}
$$
On the Sun $d_{p} \simeq 2 \, m$.
We want 
$$
L_{0} \gg d_{p}
$$
with $L_{0}$ the typical size of a coronal mass ejection. 

We apply the following simplifications: 
$$
\begin{align}
 m_{p} \gg m_{e}  ;&&  n_{p} \sim n_{e} = n 
\end{align}
$$
the quasi-neutrality condition is also justified by the fact that any dishomogeneities in $n_{p}$ or $n_e$ is quickly restored by the small scale electric field using high frequencies.
### Continuity equations
So
$$
\rho_{c} = e\left( n_{p} - n_{i} \right) =0 
$$
and
$$
\begin{align}
 &\rho = \sum_{\alpha} m_{\alpha}n_{\alpha} = m_{p}n_{p} + n_{e}m_{e} = n \left( m_{p}+m_{e} \right) \simeq nm_{p} \\[.8em]
& \rho \bar{U} = m_{p}n_{p}\bar{U}_{p} + m_{e}n_{e}\bar{U}_{e} \simeq \rho \bar{U}_{p}
\end{align}
$$
So $\rho \sim nm_{p}$ and $\bar{U} \sim \bar{U}_{p}$. 
Now we use the two variables $\rho$ and $\bar{U}$, we multiply the continuity equation $(A)$ for a factor $m_{\alpha}$ 
$$
\begin{align}
 \begin{cases}
\dfrac{ \partial n_{p} }{ \partial t } + \nabla \cdot \left( n_{p}\bar{U}_{p} \right) = 0 \\[.8em]
\dfrac{ \partial n_{e} }{ \partial t } + \nabla \cdot \left( n_{e}\bar{U}_{e} \right) = 0 
\end{cases} 
&&\implies&& 
\begin{cases}
\dfrac{ \partial m_{p}n_{p} }{ \partial t } + \nabla \cdot \left( m_{p}n_{p}\bar{U}_{p} \right) = 0 \\[.8em]
\dfrac{ \partial m_{e}n_{e} }{ \partial t } + \nabla \cdot \left( m_{e}n_{e}\bar{U}_{e} \right) = 0
\end{cases}
\end{align}
$$
We sum them and we obtain
$$
 \frac{ \partial \rho }{ \partial t } + \nabla \cdot \left( \rho \bar{U} \right) = 0
$$
### Euler equations (sum)
For the moment equation $(B)$ first we sum the equation for protons and the one for electrons 
$$
 \begin{align}
\frac{ \partial \left[ n\left( m_{p}\bar{U}_{p} + \cancel{ m_{e}\bar{U}_{e} } \right)  \right]  }{ \partial t } &+ \nabla \cdot \left[ n \left(  m_{p}\bar{U}_{p}\bar{U}_{p} + \cancel{ m_{e}\bar{U}_{e}\bar{U}_{e} }  \right)  \right] + \\[.8em]
&+ \nabla \left( P_{p} + P_{e} \right) + en \left[ \bar{U}_{e}\times \bar{B} - \bar{U}_{p}\times\bar{B} \right]  = 0
\end{align}
$$
$$
 \begin{align}
\implies &\frac{ \partial n m_{p}\bar{U}  }{ \partial t } + \nabla \cdot \left( n  m_{p}\bar{U}\bar{U} \right) + \nabla \left( P_{tot} \right) + en \left( \bar{U}_{e} - \bar{U}_{p} \right)\times\bar{B}  = 0 \\[.8em]
\implies & \frac{ \partial \rho \bar{U}  }{ \partial t } + \nabla \cdot \left( \rho\bar{U}\bar{U} \right) + \nabla \left( P_{tot} \right) -\bar{J}\times\bar{B}  = 0 
\end{align}
$$
### Euler equations (difference)
Now we multiply equation $(B)$ by the factor $\left\lvert  q_{\alpha}  \right\rvert /m_{\alpha}$ 
$$
 \begin{cases}
\displaystyle\frac{ \partial (en_{p}\bar{U}_{p}) }{ \partial t } + \nabla \cdot \left[ e n_{p} \bar{U}_{p} \bar{U}_{p} \right] + \frac{e}{m_{p}} \nabla P_{p} - \frac{e^2}{m_{p}} n_{p} \left[ \bar{E} + \bar{U}_{p}\times \bar{B} \right] = 0 &&(1) \\[.8em]
 \displaystyle\frac{ \partial (en_{e}\bar{U}_{e}) }{ \partial t } + \nabla \cdot \left[ e n_{e} \bar{U}_{e} \bar{U}_{e} \right] + \frac{e}{m_{e}} \nabla P_{e} - \frac{e^2}{m_{e}} n_{e} \left[ \bar{E} + \bar{U}_{e}\times \bar{B} \right] = 0  &&(2)
\end{cases}
$$
We evaluate the first equation minus the second ($(1)-(2)$)
$$
\begin{align}
 \frac{ \partial \bar{J} }{ \partial t } + \nabla \cdot & \left[ en \left( \bar{U}_{p}\bar{U}_{p} - \bar{U}_{e}\bar{U}_{e} \right)  \right] + \frac{e}{m_{p}} \nabla P_{p} - \frac{e}{m_{e}} \nabla P_{e} + \\[.8em]
&- \frac{e^2}{m_{p}}n \left[ \bar{E} + \bar{U}_{p}\times \bar{B} \right]  - \frac{e^2}{m_{e}}n \left[ \bar{E} + \bar{U}_{e}\times \bar{B} \right] =0 
\end{align}
$$
We multiply by $m_{e}$ and approximate $m_{e}\to 0$, so only terms $\sim 1 / m_{e}$ survive
$$
\begin{align}
 &- \cancel{ e } \nabla P_{e} - e^\cancel{ 2 } n \left[ \bar{E} + \bar{U}_{e}\times \bar{B} \right] = 0 \\[.8em]
\implies & \bar{E} = - \bar{U}_{e} \times \bar{B} - \frac{1}{n_{e}e} \nabla P_{e}  
\end{align}
$$
In which we use 
$$
\begin{align}
 \bar{J} = en \bar{U}_{p} - en \bar{U}_{e} && \implies && \bar{U}_{e} = \bar{U}_{p} - \frac{\bar{J}}{n_{e}e}
\end{align}
$$
so 
$$
 \bar{E} = - \bar{U} \times \bar{B} + \frac{1}{n_{e}e} \bar{J} \times \bar{B} - \frac{1}{n_{e}e} \nabla P_{e}
$$
### Ampère-Maxwell law
From Ampère-Maxwell law $(F)$ we have
$$
 \nabla \times \bar{B} = \mu_{0} \bar{J} + \cancel{ \frac{1}{c} \frac{ \partial \bar{E} }{ \partial t } } 
$$
We neglect the second therm because we are not in the relativistic regime (we are studying low frequencies), so
$$
 \bar{J} = \frac{1}{\mu_{0}} \nabla \times \bar{B}
$$
### Obtaining the Ideal Ohm's law
We use this result for $\bar{J}$ in the expression for $\bar{E}$ 
$$
 \bar{E} = - \bar{U} \times \bar{B} + \frac{1}{\mu_{0}m_{e}} \left( \nabla \times \bar{B} \right)  \times \bar{B} - \frac{1}{n_{e}e} \nabla P_{e}
$$
Now we divide by the tipical lenght of the system $L_{0}$ and we obtain
$$
 \begin{align}
&\nabla = L_{0}^{-1}\tilde{\nabla}, && \bar{U} = U_{0} \tilde{ \bar{U} }  \\[.8em]
&\bar{B} = B_{0} \tilde{ \bar{B} }, && P = P_{0} \tilde{P}  \\[.8em]
 & n = n_{0} \tilde{n}
\end{align}
$$
So 
$$
 \frac{\tilde{ \bar{E} }E_{0}}{L_{0}} = - \bar{U} \times \bar{B} \frac{U_{0}B_{0}}{L_{0}} + \cancel{ \frac{B_{0}^2}{\mu_{0}n_{0}e L_{0}^2} \left( \tilde{\nabla} \times \tilde{\bar{B}} \right) \times \tilde{\bar{B}} } - \cancel{ \frac{P_{0}}{n_{0}eL_{0}^2} \tilde{\nabla} \tilde{P}_{e} }
$$
The last two terms are comparable to $L_{0}^{-2}$ so they are negligible.
HERE why is this negligible?
We finally obtain the ideal Ohm's law
$$
 \bar{E} = - \bar{U} \times \bar{B}
$$
which is valid also in observation of the solar wind, in the heliosphere, in the magnetopause, ecc.

### Summary of compressible MHD
$$
 \begin{cases}
\displaystyle \frac{ \partial \rho }{ \partial t } + \nabla \cdot \left( \rho \bar{U} \right) = 0 \\[.8em]
\displaystyle \frac{ \partial \left( \rho \bar{U} \right)  }{ \partial t } + \nabla \cdot \left[ \rho \bar{U} \bar{U} \right] + \nabla P_{tot} - \bar{J} \times \bar{B} = 0 \\[.8em]
 P = A\rho^\gamma \\[.8em]
\dfrac{ \partial \bar{B} }{ \partial t } = - \nabla \times \bar{E} = \nabla \times \left( \bar{U} \times \bar{B} \right) \\[.8em]
 \nabla \cdot \bar{B} = 0
\end{cases}
$$
with 
$$
 \begin{cases}
\bar{E} = -\bar{U}\times \bar{B} \\[.8em]
\bar{J} = \dfrac{1}{\mu_{0}} \nabla \times \bar{B}
\end{cases}
$$
We recall the Faraday's law (which is used for magnetic field on Earth)
$$
 \frac{ \partial \bar{B} }{ \partial t } = \nabla \times \left( \bar{U} \times \bar{B} \right) 
$$

# Incompressible Ideal Magnetohydrodynamics
The incompressibility condition is
$$
\begin{align}
 U \ll c_{s} && \implies && \nabla \cdot \bar{U} = 0
\end{align}
$$
with
$$
  c_{s}^2 = \frac{ \partial P }{ \partial \rho }  \to \infty
$$
We rewrite the **continuity equation** as
$$
\begin{align}
&\frac{ \partial \rho }{ \partial t } + \nabla \cdot \left( \rho \bar{U} \right) = 0 \\[.8em]
 \implies&\frac{ \partial \rho }{ \partial t } + \rho \nabla \cdot \bar{U} +  \bar{U} \nabla \rho = 0 \\[.8em]
 \implies&\frac{ \partial \rho }{ \partial t } +  \bar{U} \cdot \nabla \rho = 0  \\[.8em]
\implies& \left( \frac{ \partial  }{ \partial t } + \bar{U} \cdot \nabla \right) \rho = 0  \\[.8em]
\implies& \frac{d}{dt}  \rho = 0 
\end{align}
$$
where the last derivative is a total (Lagrangian) derivative.
From now on this will be trivial and $\rho_{0}$ will be the tipical density.

The **Euler equation** is (using the continuity equation)
$$
\begin{align}
 &\frac{ \partial \left( \rho \bar{U} \right)  }{ \partial t } + \nabla \cdot \left[ \rho \bar{U} \bar{U} \right] + \nabla P_{tot} - \bar{J} \times \bar{B} = 0 \\[.8em]
\implies&\rho \frac{ \partial \bar{U} }{ \partial t } + \bar{U} \frac{ \partial \rho }{ \partial t } + \bar{U} \nabla \cdot \left( \rho \bar{U} \right) + \rho \left( \bar{U} \cdot \nabla  \right) \bar{U} + \nabla P_{tot}- \bar{J} \times \bar{B} = 0 \\[.8em]
\implies&\rho \frac{ \partial \bar{U} }{ \partial t } + \bar{U} \underbrace{ \left[ \frac{ \partial \rho }{ \partial t } + \nabla \cdot \left( \rho \bar{U} \right) \right] }_{ =0 } + \rho \left( \bar{U} \cdot \nabla  \right) \bar{U} + \nabla P_{tot}- \bar{J} \times \bar{B} = 0 \\[.8em]
\implies& \frac{ \partial \bar{U} }{ \partial t } + \left( \bar{U} \cdot \nabla  \right) \bar{U} = - \frac{\nabla P_{tot}}{\rho} + \frac{\bar{J} \times \bar{B}}{\rho} \\[.8em]
\implies& \frac{ \partial \bar{U} }{ \partial t } + \left( \bar{U} \cdot \nabla  \right) \bar{U} = - \nabla \left( \frac{P_{tot}}{\rho_{0}} \right) + \frac{(\nabla \times \bar{B}) \times \bar{B}}{\mu_{0}\rho_{0}} 
\end{align}
$$
And for the magnetic field (**Faraday's law**) we have
$$
 \begin{align}
\frac{ \partial \bar{B} }{ \partial t } &= \nabla \times \left( \bar{U} \times \bar{B} \right) = \\[.8em]
&= -\bar{U} \cdot \nabla \bar{B} + \bar{B} \cdot \nabla \bar{U} - \cancel{ \bar{U} \nabla\cdot \bar{B} } + \cancel{ \bar{B} \nabla \cdot \bar{U} } = \\[.8em]
&= -\bar{U} \cdot \nabla \bar{B} + \bar{B} \cdot \nabla \bar{U}
\end{align}
$$
(Parker said "this is the minimum")

So we have 
$$
 \begin{cases}
\displaystyle\frac{ \partial \bar{U} }{ \partial t } + \bar{U} \cdot \nabla \bar{U} = -  \nabla \left( \frac{P}{\rho_{0}} \right)  + \frac{(\nabla \times \bar{B}) \times \bar{B}}{\mu_{0}\rho_{0}} \\[.8em]
\displaystyle\frac{ \partial \bar{B} }{ \partial t } = - \bar{U} \cdot \nabla \bar{B} + \bar{B} \cdot \nabla \bar{U}
\end{cases}
$$
with $\nabla \cdot \bar{U} = \nabla \cdot \bar{B} = 0$.

The **EoS in MHD**.
We leave the thermodynamics ($c_{s} \to \infty$) and the pressure comes from $\nabla \cdot \bar{U} = 0$.
Why?
We use 
$$
\frac{ \partial  }{ \partial t }  \nabla \cdot \bar{U} = 0
$$
and from the divergence of Euler equation we have
$$
 \begin{align}
&\cancel{ \frac{ \partial (\nabla \cdot \bar{U}) }{ \partial t } } + \nabla \cdot \left[ \bar{U} \cdot \nabla \bar{U}  \right] = - \nabla ^2 \left( \frac{P}{\rho_{0}} \right) + \nabla \cdot \left( \frac{(\nabla \times \bar{B}) \times \bar{B}}{\mu_{0}\rho_{0}} \right)  \\[.8em]
 \implies& \nabla^2 P = - \rho_{0} \,\nabla \cdot \left[ \bar{U} \cdot \nabla \bar{U} - \frac{(\nabla \times \bar{B}) \times \bar{B}}{\mu_{0}\rho_{0}} \right] \equiv G(\bar{x},t)
\end{align}
$$
So we need to solve a laplace differential equation in order to find the pressure. 

### Alfvénic units
We reduce the number of parameters
$$
 \begin{cases}
\displaystyle\frac{ \partial \bar{U} }{ \partial t } + \bar{U} \cdot \nabla \bar{U} = -  \nabla \left( \frac{P}{\rho_{0}} \right)  + \frac{(\nabla \times \bar{B}) \times \bar{B}}{\mu_{0}\rho_{0}} \\[.8em]
\displaystyle\frac{ \partial \bar{B} }{ \partial t } = \nabla \times \left(  \bar{U} \times \bar{B} \right) 
\end{cases}
$$
we define the adimensional quantities
$$
 \begin{align}
&x = L_{0} \tilde{x}, && \bar{U} = U_{0} \tilde{\bar{U}}= \frac{L_{0}}{T_{0}}\tilde{\bar{U}}, \\[.8em]
&t= T_{0} \tilde{t}, &&P = P_{0} \tilde{P} = \rho_{0} U_{0}^2 \tilde{P}, \\[.8em]
&\bar{B} = B_{0} \tilde{\bar{B}}
\end{align}
$$
We normalize the Euler equation
$$
 \begin{align}
& \frac{U_{0}}{T_{0}} \frac{ \partial \tilde{\bar{U}} }{ \partial \tilde{t} } + \frac{U_{0}^2}{L_{0}} \tilde{\bar{U}}\cdot \tilde{\nabla} \tilde{\bar{U}} = - \frac{P_{0}}{\rho_{0}L_{0}} \tilde{\nabla} \tilde{P} + \frac{B_{0}^2}{\rho_{0}\mu_{0}L_{0}} (\tilde{\nabla} \times \tilde{\bar{B}}) \times \tilde{\bar{B}}  \\[.8em]
\implies & \frac{ \partial \tilde{\bar{U}} }{ \partial \tilde{t} } + \tilde{\bar{U}}\cdot \tilde{\nabla} \tilde{\bar{U}} = - \tilde{\nabla} \tilde{P} + \frac{B_{0}^2T_{0}}{\rho_{0}\mu_{0}L_{0}U_{0}} (\tilde{\nabla} \times \tilde{\bar{B}}) \times \tilde{\bar{B}}
\end{align}
$$
We define the Alfvén velocity as
$$
 U_{A} = \frac{B_{0}}{\sqrt{ \rho_{0} \mu_{0} }}
$$
this velocity defines the Alfvénic plasma, where $U_{0} = U_{A}$ 
$$
 \frac{B_{0}^2T_{0}}{\rho_{0}\mu_{0}L_{0}U_{0}} = \frac{B_{0}^2}{\rho_{0}\mu_{0}} \frac{1}{U^2_{0}} = \frac{U_{A}^2}{U_{0}^2} = 1
$$
HERE do we impose the ratio to be 1? Shouldn't be present something similar to a Reynold number?
Now we normalize the magnetic field equation
$$
 \begin{align}
&\frac{B_{0}}{T_{0}} \frac{ \partial \tilde{\bar{B}} }{ \partial \tilde{t} } = \frac{U_{0}B_{0}}{L_{0}} \tilde{\nabla} \times \left( \tilde{\bar{U}} \times\tilde{\bar{B}} \right)   \\[.8em]
\implies & \frac{ \partial \tilde{\bar{B}} }{ \partial \tilde{t} } =  \tilde{\nabla} \times \left( \tilde{\bar{U}} \times\tilde{\bar{B}} \right)
\end{align}
$$
So finally we have the normalized set of equations
$$
 \begin{cases}
 \displaystyle \frac{ \partial \tilde{\bar{U}} }{ \partial \tilde{t} } + \tilde{\bar{U}}\cdot \tilde{\nabla} \tilde{\bar{U}} = - \tilde{\nabla} \tilde{P} +(\tilde{\nabla} \times \tilde{\bar{B}}) \times \tilde{\bar{B}}\\[.8em]
\dfrac{ \partial \tilde{\bar{B}} }{ \partial \tilde{t} } =  \tilde{\nabla} \times \left( \tilde{\bar{U}} \times\tilde{\bar{B}} \right)
\end{cases}
$$
Now, to simplify the notation, we remove the tilde from every quantity ($\tilde{f} \to f$) 
We are in Alfvénic units
$$
  \begin{cases}
 \displaystyle \frac{ \partial \bar{U} }{ \partial t } + \bar{U}\cdot \nabla \bar{U} = - \nabla P +(\nabla \times \bar{B}) \times \bar{B}\\[.8em]
\dfrac{ \partial \bar{B} }{ \partial t } =  \nabla \times \left( \bar{U} \times\bar{B} \right)
\end{cases}
$$
