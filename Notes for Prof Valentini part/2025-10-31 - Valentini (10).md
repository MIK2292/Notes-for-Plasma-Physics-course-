Recap
$$
 \omega_{R} = \omega_{pe} \sqrt{  1 + 3 k^2 \lambda_{De}^2 }
$$
Langmuir waves 
$$
\left|\frac{\omega_{I}}{\omega_{R}}\right| \ll 1 \ \ \ \ \ \ \text{and }\ \ \ \ v_{\phi} = \frac{\omega_{R}}{k} \gg v_{th \alpha}
$$
With the condition (yet to be discussed)
$$
k^2 \lambda_{De}^2 \ll 1
$$
We got
$$
\omega_{I} = \left. \frac{\pi}{2} \frac{\omega_{R}^2}{k^2n_{\alpha 0}} \frac{ \partial F_{\alpha 0}(u) }{ \partial u } \right|_{\omega_{R} / k} 
$$

Equation of motion for one electron: 
$$
m_{e} \frac{d^2}{dt^2} x = -e E_{0} \sin(kx) \implies \frac{d^2}{dt^2} x + \frac{eE_{0}}{m_{e}} \sin(kx) = 0
$$
The electron moves with the wave
There is resonant wave-particle interaction
$$
kx \ll 1 \implies \frac{d^2}{dt^2} x + \underbrace{ \frac{eE_{0}k}{m_{e}} }_{ \omega^2 }x = 0, \ \ \ \ \ \ \ \ \ \ T = 2\pi \sqrt{  \frac{m_{e}}{eE_{0}k} }
$$
with $T$ being the trapping time, the period of oscillation of a charged particle in the potential hole. 
Particles are "trapped" and they oscillate between one wavefront and the other. 

The Landau scenario is
$$
\omega_{I}^{-1} < \tau
$$

The O'Neil scenario (which is non-linear) is 
$$
\omega_{I}^{-1} \approx \tau
$$

$$
\tau \approx \sqrt{ \frac{m_{e}}{eE_{0}k} }
$$
$$
E(x) = E_{0} \sin (kx)
$$
$$
E = - \frac{d}{dx} \phi \implies \phi = - \int E \,dx = \underbrace{ \frac{E_{0}}{k} }_{ \phi_{0} } \cos (kx) 
$$
The energy is
$$
\mathcal{E} = \frac{1}{2} m_{e} (v-v_{\phi})^2 - e \phi_{0} \cos(kx) = \text{const}
$$
we evaluate it at $v=v_{\phi}$ (where we also have $\phi = \phi_{\text{max}}$)
$$
 \mathcal{E} = -e \phi_{\text{max}}
$$
and
$$
\begin{align}
&(v-v_{\phi})^2 = \frac{2}{m_{e}} \left[ -e \phi_{\text{max}} + e \phi_{0} \cos (kx) \right]  \\[.8em]
\implies &v = v_{\phi} \pm \sqrt{ \frac{2}{m_{e}} \left[ -e \phi_{\text{max}} + e \phi_{0} \cos (kx) \right]  }
\end{align}
$$

 &= - \sqrt{  \frac{\pi}{8} } \frac{\omega_{pe }\omega_{pe}^3}{k^3 v_{th, e}^3} \exp \left[ - \frac{m_{e}}{2k_{B}T_{e 0} } \frac{1}{k^2} \omega_{pe}^2 (1 +3k^2 \lambda_{De}^2)  \right] = \\[.8em]
 &= - \sqrt{  \frac{\pi}{8} } \frac{\omega_{pe }}{k^3 \lambda_{De}^3} \exp \left[ - \frac{1}{2k^2\lambda_{De}^2 } (1 +3k^2 \lambda_{De}^2)  \right] = \\[.8em]
 &= - \sqrt{  \frac{\pi}{8} } \frac{\omega_{pe }}{k^3 \lambda_{De}^3} \exp \left[ - \frac{1}{2k^2\lambda_{De}^2 } - \frac{3}{2}  \right]

## Low frequency regime 
$$
\left| \frac{\omega_{I}}{\omega_{R}}\right| \ll 1, \ \ \ \ \ \ v_{th,i} \ll \frac{\omega_{R}}{k} \ll v_{th,e}
$$
PIC LowFreqRegime
![[Screenshot from 2025-11-18 13-17-09.png|600]]
$$
\begin{align}
D_{R}(k, \omega_{R}) = 0 &&\implies &&\omega_{R} = \omega_{R} (k)  
\end{align}
$$
$$
\begin{align}
0 = D_{R}(k,\omega_{R}) &= 1- \sum_{\alpha} \frac{\omega_{p \alpha}^2}{k^2n_{\alpha 1}} P \int_{-\infty}^{\infty} \frac{ \partial F_{\alpha 0}(u) / \partial u }{u - \omega_{R} / k}  \, du = \\[.8em]
&= 1- \frac{\omega_{p i}^2}{k^2n_{0}} P \int_{-\infty}^{\infty} \frac{ \partial F_{i 0}(u) / \partial u }{u - \omega_{R} / k}  \, du - \frac{\omega_{p e}^2}{k^2n_{0}} P \int_{-\infty}^{\infty} \frac{ \partial F_{e 0}(u) / \partial u }{u - \omega_{R} / k}  \, du 
\end{align}
$$
We already solved the first integral for ions, so we substitute the previous result.
We also say, for the second integral, that the majority of particles has $u \gg \omega_{R} /k$ 
$$
0 = D_{R}(k,\omega_{R}) = 1- \frac{\omega_{p i}^2}{\cancel{ k^2n_{0} }} \frac{\cancel{ n_{0}k^2 }}{\omega_{R}^2} \left[ 1+3 \frac{k^2 \lambda_{Di}^2 \omega_{p i}^2}{\omega_{R}^2} \right]  \underbrace{ - \frac{\omega_{p e}^2}{k^2n_{0}} P \int_{-\infty}^{\infty} \frac{1}{u} \frac{ \partial F_{e 0}(u) }{ \partial u }  \, du  }_{ \mathcal{I} }
$$
PIC electrons
![[Screenshot from 2025-11-18 13-17-18.png|400]]
We can solve the second integral as follows:
first we substitute $F_{e 0}(u)$ and derive
$$
\mathcal{I} = - \frac{\omega_{p e}^2}{k^2\cancel{ n_{0} }} P \int_{-\infty}^{\infty} \frac{1}{\cancel{ u }} \left[ -\frac{\cancel{ n_{0} }m_{e}^{3/2}}{\left( 2\pi \right)^{1/2} \left( k_{B}T_{e 0} \right) ^{3/2} }\cdot \cancel{ u } \exp \left( - \frac{m_{e}}{2k_{B}T_{e 0}} u^2 \right)  \right]   \, du
$$
then we use the substitution
$$
\begin{align}
y^2 = u^2\frac{m_{e}}{2k_{B}T_{e 0}} &&\implies&& y = \frac{m_{e}^{1/2}}{(2k_{B}T_{e 0})^{1/2}}u
\end{align}
$$
and
$$
\mathcal{I} =  \frac{\omega_{p e}^2}{k^2} \frac{m_{e}^{\cancel{ 3/2 }}}{\left( \cancel{ 2 }\pi \right)^{1/2} \left( k_{B}T_{e 0} \right) ^{\cancel{ 3/2 }} } \underbrace{ \int_{-\infty}^{\infty} \exp \left( - y^2 \right)    \, dy }_{ \sqrt{ \pi } } \cancel{ \sqrt{ \frac{2k_{B}T_{e 0}}{m_{e}} } } = \frac{1}{k^2 \lambda_{De}^2}
$$
$$
\implies \ D_{R}(k,\omega_{R}) = 1- \frac{\omega_{p i}^2}{\omega_{R}^2} \left[ 1+3 \frac{k^2 \lambda_{Di}^2 \omega_{p i}^2}{\omega_{R}^2} \right] + \frac{1}{k^2 \lambda_{De}^2} = 0
$$
We solve for $\omega_{R}$
$$
\implies \left( 1+ \frac{1}{k^2 \lambda_{De}^2} \right) \omega_{R}^4 - \omega_{p i}^2 \omega_{R}^2 - 3k^2 \lambda_{Di}^2 \omega_{p i}^4 = 0 
$$
and
$$\ \ \ \ \ \ \ \ 
\begin{align}
\omega_{R}^2 &= \frac{\omega_{p i}^2 \pm \sqrt{ \omega_{p i}^4 + 12 k^2 \lambda_{Di}^2 \omega_{p i}^4 \left( \frac{1+k^2\lambda_{De}^2}{k^2\lambda_{De}^2} \right)  }}{2 \cdot \left( \frac{1+k^2\lambda_{De}^2}{k^2\lambda_{De}^2} \right)  } = \\[.8em]
&= \frac{1}{2}\frac{k^2\lambda_{De}^2}{1+k^2\lambda_{De}^2} \left[ \omega_{p i}^2 \pm \omega_{p i}^2 \sqrt{ 1+ 12 \frac{T_{i 0}}{T_{e 0}}\left( 1+ k^2\lambda_{De}^2 \right)  } \right]  = \\[.8em]
&= \frac{\omega_{p i}^2}{2} \frac{k^2\lambda_{De}^2}{1+k^2\lambda_{De}^2} \left[ 1 \pm  \sqrt{ 1+ 12 \frac{T_{i 0}}{T_{e 0}}\left( 1+ k^2\lambda_{De}^2 \right)  } \right] \approx \\[.8em]
&\approx \frac{\omega_{p i}^2}{2} \frac{k^2\lambda_{De}^2}{1+k^2\lambda_{De}^2} \left[ 1 \pm  \left( 1+6 \frac{T_{i 0}}{T_{e 0}} + \dots \right)  \right] 
\end{align}
$$
Where we used
$$
\lambda_{Di}^2 = \frac{k_{B}T_{i 0}}{4\pi n_{0} e^2} \frac{T_{e 0}}{T_{e 0}} = \lambda_{De}^2 \frac{T_{i 0}}{T_{e 0}}
$$
Now we only keep the ($+$) solution in order to avoid imaginary $\omega_{R}$, and we obtain
$$
\omega_{R} = \pm \frac{\omega_{p i}k\lambda_{De}}{(1 + k^2 \lambda_{De}^2)^{1/2}} \left( 1+ \frac{3T_{i 0}}{T_{e 0}} \right) ^{1/2} 
$$
and we also find the ion sound speed as
$$
\omega_{p i} \lambda_{De} = \left[ \frac{\cancel{ 4\pi n_{0}e }}{m_{i}} \frac{k_{B}T_{e 0}}{\cancel{ 4\pi n_{0}e }} \right] ^{1/2} =  c_{s}
$$
so 
$$
\omega_{R} = \pm \frac{kc_{s}}{\sqrt{ 1+k^2 \lambda_{De}^2}} \sqrt{ 1 + 3 \frac{T_{i 0}}{T_{e 0}} }
$$
which are the ion acoustic waves. 

 and we can affirm that, for $k^2\lambda_{De}^2 \ll 1$ 
$$
\begin{align}
\left| \frac{\omega_{I}}{\omega_{R}} \right| \ll 1 &&\implies&& \frac{T_{i 0}}{T_{e 0}} \ll 1
\end{align}
$$
