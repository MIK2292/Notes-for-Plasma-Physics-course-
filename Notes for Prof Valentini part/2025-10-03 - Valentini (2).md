## High frequency regime
ions stay fixed, $n_{i 0}$ 
only equation for electrons 
$$
\begin{align}
\frac{ \partial n_{e} }{ \partial t }  + \nabla \cdot \left( n_{e}\bar{U}_{e} \right) &= 0 \\[0.6em]
m_{e}n_{e} \left[ \frac{ \partial \bar{U}_{e}}{ \partial t }  + \bar{U}_{e} \cdot \nabla \bar{U}_{e} \right]& = - \nabla p_{e} - q_{e} n_{e} \nabla \Phi \\[0.6em]
- \nabla^2 \Phi& = 4 \pi \sum _{\alpha} q_{\alpha} n_{\alpha}
\end{align}
$$
$$
n_{e} = n_{e 0} + n_{1}, \ \ \ \ \bar{U}_{e} = \bar{U}_{e 1}, \ \ \ \ \Phi = \Phi_{1}
$$
and
$$
\begin{align}
\frac{  \partial }{ \partial t } \left(  n_{e 0} + n_{e 1}  \right) + \nabla \cdot \left( \left(  n_{e 0} + n_{e 1}  \right) \cdot\bar{U}_{e 1} \right) &= 0 \\[0.6em]
\frac{  \partial }{ \partial t } \left(  n_{e 0}   \right) +   n_{e 0}\nabla \cdot \left(  \bar{U}_{e 1} \right) &= 0
\end{align}
$$
$$
\begin{align}
m_{e}\left(  n_{e 0} + \cancel{ n_{e 1} }  \right) \left[ \frac{ \partial \bar{U}_{e 1}}{ \partial t }  \right]& = - k_{B}T_{e} \nabla \left( \cancel{  n_{e 0} } + n_{e 1}  \right) - e \left(  n_{e 0} + \cancel{ n_{e 1} }  \right)\nabla \Phi_{1} \\[0.6em]
- \nabla^2 \Phi& = 4 \pi \sum _{\alpha} q_{\alpha} n_{\alpha}
\end{align}
$$
we get 
$$
\begin{cases}
\dfrac{  \partial }{ \partial t } \left(  n_{e 1}   \right) +   n_{e 0}\nabla \cdot  \bar{U}_{e 1} = 0  & (A)\\[0.6em]
m_{e}n_{e 0} \dfrac{ \partial \bar{U}_{e 1} }{ \partial t }  = - k_{B}T_{e 0} \nabla n_{e 1} + e n_{e 0} \nabla \Phi_{1} &(B) \\[0.8em]
\nabla^2 \Phi_{1} = 4 \pi e n_{e 1} &(C)
\end{cases}
$$
we use fourier
$$
\begin{cases}
n_{e 1} = \hat{n}_{e 1} \exp \left[ i \left( \bar{k} \cdot \bar{r} - \omega t \right)  \right] \\[0.6em]
\bar{U}_{e 1} = \hat{\bar{U}}_{e 1} \exp \left[ i \left( \bar{k} \cdot \bar{r} - \omega t \right)  \right] \\[0.6em]
\Phi_{e 1} = \hat{\Phi}_{e 1} \exp \left[ i \left( \bar{k} \cdot \bar{r} - \omega t \right)  \right]
\end{cases}
$$
for witch 
$$
\frac{ \partial  }{ \partial t }  \to - i \omega, \ \ \ \ \ \ \frac{ \partial  }{ \partial r } \to i \bar{k}
$$
and
$$
\begin{cases}
- i \omega \hat{n}_{e 1} + n_{e 0}\, i \bar{k} \cdot \hat{\bar{U}}_{e 1} = 0  & (A)\\[0.6em]
m_{e}n_{e 0} \left( -i\omega \right) \hat{\bar{U}}_{e 1} = - k_{B}T_{e 0} i \bar{k} \, n_{e 1} + e n_{e 0} i \bar{k} \,\hat{\Phi}_{1} &(B) \\[0.8em]
- k^2 \hat{\Phi}_{1} = 4 \pi e \hat{n}_{e 1} &(C)
\end{cases}
$$
Dividing $(A)$ for $in_{e 0}$ we have
$$
\bar{k} \cdot \hat{\bar{U}}_{e 1} = \omega \frac{ \hat{n}_{e 1}}{n_{e 0}}
$$
Multiplying $(B)$ for $k/i$ we have
$$
-m_{e}n_{e 0} \omega \bar{k} \cdot \hat{\bar{U}}_{e 1} = - k_{B}T_{e 0} k^2 \hat{n}_{e 1} + e n_{e 0} k^2 \hat{\Phi}_{1}
$$
and using
$$
v_{th\,e}^2 = \frac{k_{B}T_{e 0 }}{m_{e}}
 $$
we have
$$
-n_{e 0} \omega \bar{k} \cdot \hat{\bar{U}}_{e 1} = - v_{th\,e}^2 k^2 \hat{n}_{e 1} + \frac{e n_{e 0}}{m_{e}} k^2 \hat{\Phi}_{1}
$$
now we use $(A)$ 
$$
-n_{e 0} \omega^2 \frac{\hat{n}_{e 1}}{n_{e 0}} = - v_{th\,e}^2 k^2 \hat{n}_{e 1} + \frac{e n_{e 0}}{m_{e}} k^2 \hat{\Phi}_{1}
$$
$$
\begin{align}
\implies & \hat{n}_{e 1} \left( - \omega^2 + k^2 v_{th\,e}^2 \right)  = \frac{e n_{e 0}}{m_{e}} k^2 \hat{\Phi}_{1} \\[0.6em]
\implies & \hat{n}_{e 1}  = \frac{e n_{e 0}}{m_{e}\left( - \omega^2 + k^2 v_{th\,e}^2 \right)} k^2 \hat{\Phi}_{1}
\end{align}
$$
We use this result in $(C)$
$$
- k^2 \hat{\Phi}_{1}  = \frac{4\pi e^2}{m_{e}} \frac{n_{e 0}k^2 \hat{\Phi}_{1}}{- \omega^2 + k^2 v_{th\,e}^2}
$$
using 
$$
\omega_{p}^2 = \frac{4\pi e^2 n_{e 0}}{m_{e}}
$$
we have
$$
k^2 \hat{\Phi}_{1} \left[ 1 - \frac{\omega_{p}^2}{ \omega^2 - k^2 v_{th\,e}^2} \right]  = 0
$$
We solve for $k$ 
$k=0$ is not useful
we want $\omega^2 - k^2 v_{th\,e}^2 = \omega_{p}^2$  and
$$
\omega = \pm \sqrt{  \omega_{p}^2 + k^2 v_{th\,e}^2 }= \pm \omega_{p} \sqrt{  1 + \frac{k^2 v_{th\,e}^2}{\omega_{p}^2} }
$$
which is the dispersion relation
also
$$
\frac{v_{th \, e}^2}{\omega_{p}^2} = \frac{k_{B}T_{e 0}\cancel{ m_{e} }}{\cancel{ m_{e} }4\pi n_{e 0}e^2} \equiv \lambda_{D}^2

which is the Debye lenght

# Low frequency regime
$$
\begin{align}
\frac{ \partial n_{\alpha} }{ \partial t }  + \nabla \cdot \left( n_{\alpha}\bar{U}_{\alpha} \right) &= 0 \\[0.6em]
m_{\alpha}n_{\alpha} \left[ \frac{ \partial \bar{U}}{ \partial t }  + \bar{U}_{\alpha} \cdot \nabla \bar{U}_{\alpha} \right]& = - \nabla p_{\alpha} - q_{\alpha} n_{\alpha} \nabla \Phi \\[0.6em]
- \nabla \Phi& = 4 \pi \sum _{\alpha} q_{\alpha} n_{\alpha} \\[0.6em]
p_{\alpha} &= n_{\alpha}k_{B}T_{\alpha} \\[0.6em]
T_{\alpha 0} &= const 
\end{align}
$$
(isothermal EoS)
ions can move
assumption: $m_{e} \to 0$, so the second equation for electrons becomes
$$
\begin{align}
0 &= - \nabla n_{e} k_{B}T_{e 0} - q_{e} n_{e} \nabla \Phi  \\[0.6em]
0&= - \frac{1}{n_{e}} \nabla k_{B}T_{e 0} n_{e} + e \nabla \Phi =\\[0.6em]
&= - \nabla k_{B}T_{e 0} \ln n_{e} + e \nabla \Phi =\\[0.6em]
&= \nabla \left( e \Phi - k_{B}T_{e} \ln n_{e} \right) \\[1.2em] 
\implies \ & e \Phi - k_{B}T_{e} \ln n_{e} \equiv \beta
\end{align}
$$
with $\beta$ homogeneous in space
evaluating $\beta$ at equilibrium
$$
\cancel{ e \Phi_{0} } - k_{B}T_{e} \ln n_{e 0} = \beta \ \ \ 
\implies \ \ \ \beta = - k_{B}T_{e 0} \ln n_{e 0}
$$
using again the def of $\beta$
$$
e \Phi = k_{B}T_{e 0} \left( \ln n_{e}  -\ln n_{e 0} \right) \ \ \ 
\implies \ \ \  \frac{e\Phi}{k_{B}T_{e 0}} = \ln \left( \frac{n_{e}}{n_{e 0}} \right)
$$
and we isolate $n_{e}$ 
$$
n_{e} = n_{e 0} \exp \left(  \frac{e\Phi}{k_{B}T_{e 0}} \right) = n_{e 0} \exp \left(  \frac{e\Phi_{1}}{k_{B}T_{e 0}} \right) \approx n_{e 0}  \left(  1 + \frac{e\Phi_{1}}{k_{B}T_{e 0}} \right) 
$$
so we finally have a formula for $n_{e}$ 
later we wil solve it also or ions

Linear set of equations for protons (cold, $\nabla p_{i} \ll q_{i}n_{i}\nabla \Phi$)
$$
\begin{cases}
\dfrac{  \partial }{ \partial t } \left(  n_{i 1}   \right) +   n_{i 0}\nabla \cdot  \bar{U}_{i 1} = 0  & (A)\\[0.6em]
m_{i}n_{i 0} \dfrac{ \partial \bar{U}_{i 1} }{ \partial t }  = - e n_{i 0} \nabla \Phi_{1} &(B) \\[0.8em]
- \nabla^2 \Phi_{1} = 4 \pi e \left[ n_{i } - n_{e}  \right] &(C)
\end{cases}
$$
we have for $(C)$ (using $n_{e 0} = n_{i 0} = n_{0}$)
$$
- \nabla^2 \Phi_{1} = 4 \pi e \left[ n_{i } - n_{e} \right] = 4 \pi e \left[ \cancel{ n_{i 0} } + n_{i 1} - \cancel{ n_{e 0} } - n_{e 1} \right] = 4 \pi e \left[ n_{i 1} - n_{e 1} \right] 
$$
and using the previous result we have
$$
- \nabla^2 \Phi_{1} = 4\pi e \left[ n_{i 1} - n_{e 0} \left( 1+\frac{e\Phi_{1}}{k_{B}T_{e 0}} \right)  \right] 
$$
we go to fourier space
$$
\begin{cases}
- i \omega \hat{n}_{i 1} + n_{0}\, i \bar{k} \cdot \hat{\bar{U}}_{i 1} = 0  & (A)\\[0.6em]
m_{i}n_{i 0} \left( -i\omega \right) \hat{\bar{U}}_{i 1}= -e n_{i 0} i \bar{k} \,\hat{\Phi}_{1} &(B) \\[0.8em]
k^2 \hat{\Phi}_{1} = 4 \pi e \left[ \hat{n}_{i 1} - n_{e 0} \dfrac{e \hat{\Phi}_{1}}{k_{B}T_{e 0}} \right]  &(C)
\end{cases}
$$
From $(A)$ 
$$
\bar{k} \cdot \hat{\bar{U}}_{i 1} = \frac{\omega}{n_{i 0}} \hat{n}_{i 1}
$$
From $(B)$ 
$$
\omega m_{i} n_{i 0} \bar{k} \cdot \hat{\bar{U}}_{i 1} = e n_{i 0} k^2 \hat{\Phi}_{1}
  $$
 and using $(A)$ into this eq
$$
\begin{align}
&\omega m_{i} n_{i 0} \frac{\omega}{n_{i 0}} \hat{n}_{i 1} = e n_{i 0} k^2 \hat{\Phi}_{1} \\[0.6em]
\implies & \hat{n}_{i 1} = \frac{ek^2}{m_{i} \omega^2} n_{0} \hat{\Phi}_{1}  
\end{align}
$$
So we can rewrite $(C)$ as
$$
k^2 \hat{\Phi}_{1} = 4 \pi e \left[ \frac{ek^2}{m_{i} \omega^2} n_{0} \hat{\Phi}_{1}  - n_{e 0} \dfrac{e \hat{\Phi}_{1}}{k_{B}T_{e 0}} \right]
$$
from which 
$$
k^2 \hat{\Phi}_{1} \bigg[ 1 + \underbrace{ \frac{4\pi e^2 n_{0}}{k^2 k_{B}T_{e 0}} }_{ 1 / k^2 \lambda_{D}^2 } - \underbrace{ \frac{4\pi n_{0}e^2}{m_{i} \omega^2} }_{ \omega_{pi}^2 / \omega^2 } \bigg] = 0
\ \implies \ 
k^2 \hat{\Phi}_{1} \left[  1 + \frac{1}{k^2\lambda_{D}^2} - \frac{\omega_{pi}^2}{\omega^2} \right]  = 0
$$
so the dispersion relation is
$$
\omega^2 = \frac{\omega_{pi}^2}{1 + \frac{1}{k^2 \lambda_{D}^2}} = \frac{\omega_{p i}^2 k^2 \lambda_{D}^2}{1 + k^2 \lambda_{D}^2}
$$
and
$$
\omega = \pm \omega_{p i} k \lambda_{D} \left( 1 + k^2 \lambda_{D}^2 \right) ^{-1/2}
$$
note that 
$$
\omega_{p i} \lambda_{D} = \sqrt{ \frac{\cancel{ 4\pi n_{0}e^2 }}{m_{i}} \cdot \frac{k_{B}T_{e 0}}{\cancel{ 4\pi n_{0} e^2 } } } = \sqrt{ \frac{k_{B}T_{e 0}}{m_{i}} } = c_{s}
$$
which is the ion sound speed

so 
$$
\omega = \pm \frac{ k c_{s}}{\sqrt{ 1 + k^2 \lambda_{D}^2 }} 
$$
defines the **Ion acoustic waves**

# Kinetic theory
Hypothesis
- 1D -> $\nabla = \left( \frac{ \partial  }{ \partial x },0,0 \right)$ 
- Electrostatic approximation
- Ion frequency regime, $m_{e}\to 0$, cold protons
$$
\begin{cases}
\dfrac{ \partial n_{i} }{ \partial t' } + \dfrac{ \partial  }{ \partial x' } \left( n_{i} v_{i} \right) = 0 &(A)\\[0.6em]
m_{i}n_{i} \left[ \dfrac{ \partial v_{i} }{ \partial t' } + v_{i} \dfrac{ \partial v_{i} }{ \partial x' } \right] = - e n_{i} \dfrac{ \partial \Phi }{ \partial x' } &(B) \\[.6em]
- \dfrac{ \partial ^2 \Phi }{ \partial x'^2 } = 4\pi e \left[ n_{i}- n_{e} \right] &(C) \\[0.6em]
 n_{e} = n_{e 0} \exp \left( \dfrac{e\Phi}{k_{B}T_{e 0}} \right) &(D)
\end{cases}
$$
with
$$
n_{0} = n_{e 0} = n_{i 0}, \ \ \ \ \ \Phi_{0}= 0, \ \ \ \ \ \ v_{i 0} = 0
$$
we use (from ion acoustic case)
- the typical lenght ($\lambda_{D}$)
- the typical speed ($c_{s}$) 
- the typical frequency ($\omega_{p i}$) 
to change variables to adimensional ones
so
$$
v \leftarrow \frac{v'}{c_{s}}, \ \ \ \ \ \ x \leftarrow \frac{x'}{\lambda_{D}}, \ \ \ \ \ \ \omega \leftarrow \frac{\omega'}{\omega_{p i}}
$$
and
$$
t \leftarrow t' \omega_{p i}, \ \ \ \ \ \ n_{i} \leftarrow \frac{n_{i}'}{n_{0}}, \ \ \ \ \ \ \phi \leftarrow \frac{e\Phi}{k_{B}T_{e 0}}
$$
From $(A)$
$$
\begin{align}
&\frac{ \partial ( n n_{0} ) }{ \partial \left( t / \omega_{p i}\right) } + \frac{ \partial (nn_{0}\cdot vc_{s}) }{ \partial (x \lambda_{D}) } = 0 \\[0.6em]
\implies& \cancel{ \omega_{p i} n_{0} } \frac{ \partial n }{ \partial t } + \cancel{ \frac{n_{0}c_{s}}{\lambda_{D}} } \frac{ \partial (nv) }{ \partial x } = 0 \\[0.6em]
\implies& \frac{ \partial n }{ \partial t } +  \frac{ \partial (nv) }{ \partial x } = 0
\end{align}
$$
From $(B)$ 
$$
\begin{align}
&m_{i} n n_{0} \left[ \frac{ \partial (vc_{s}) }{ \partial (t / \omega_{p i}) } + vc_{s} \frac{ \partial (vc_{s}) }{ \partial (x\lambda_{D}) }  \right] = - e n  n_{0} \frac{ \partial (\phi \,\cdot k_{B}T_{e 0} / e )}{ \partial (x\lambda_{D}) }  \\[0.8em]
\implies &m_{i} n   
\bigg[   \omega_{p i} c_{s} \cdot \frac{ \partial v }{ \partial t } + \underbrace{ \frac{c_{s}^2}{\lambda_{D} } }_{ c_{s}\omega_{p i} } \cdot v \frac{ \partial v }{ \partial x }   
\bigg] = - \frac{\cancel{ e }n}{\lambda_{D}} \frac{k_{B}T_{e 0}}{\cancel{ e }} \frac{ \partial \phi }{ \partial x } = -n \frac{k_{B}T_{e 0}}{\lambda_{D}} \frac{ \partial \phi }{ \partial x }  \\[.8em]
\implies&\cancel{ n c_{s} \omega_{p i} } \left[ \frac{ \partial v }{ \partial t } + v \frac{ \partial v }{ \partial t }  \right]  = \cancel{ n c_{s} \omega_{p i} } \frac{ \partial \phi }{ \partial x } 
\end{align}
$$
(remembering $c_{s}^2  = k_{B}T_{e 0} / m_{i}$)

From $(C)$ 
$$
\begin{align}
 &- \frac{ \partial^2  }{ \partial (x \lambda_{D})^2 } \left( \frac{k_{B}T_{e 0}}{e} \phi \right) = 4\pi e \left[ n_{i}n_{0} - \frac{n_{e}}{n_{0}}n_{0}\right]   \\[.8em]
 \implies&- \frac{k_{B}T_{e 0}}{e\lambda_{D}^2} \frac{ \partial^2  \phi }{ \partial x^2 } = 4\pi e^2 n_{0} \left[ n_{i} - \exp(\phi)\right]   \\[.8em]
\implies&- \cancel{ \frac{1}{\lambda_{D}^2} } \frac{ \partial^2  \phi }{ \partial x^2 } = \underbrace{ \left( \cancel{ \frac{4\pi e^2 n_{0}}{k_{B}T_{e 0}} } \right) }_{ 1  / \lambda_{D}^2 } \left[ n_{i} - \exp(\phi)\right]   \\[.8em]
\end{align}
$$
Finally
$$
\begin{cases}
\dfrac{ \partial n }{ \partial t } + \dfrac{ \partial (nv) }{ \partial x }  = 0 &(A)\\[.8em]
\dfrac{ \partial v }{ \partial t } + v \dfrac{ \partial v }{ \partial x }  = - \dfrac{ \partial \phi }{ \partial x } &(B) \\[.8em]
 - \dfrac{ \partial ^2 }{ \partial x^2 }  \phi  = n - \exp (\phi) &(C)
\end{cases}
$$

# Solitons
They are solutions of constant velocity, fixed shape and non dispersive wave.
pic 05 - solitons


We use $\xi = x-Mt$ with $M = v_{0} / c_{s}$ being the Mach speed
for $\xi \to \infty$ we have  (with $()' \to \frac{d}{dt}$)
$$
\begin{align}
\phi' = 0, && \phi = 0 \\[.6em]
v'=0, && v=0 \\[.6em]
n'=0, && n=1
\end{align}
$$
and the equations become
- $(A)$
$$
\begin{align}
&\frac{ \partial n }{ \partial \xi } \frac{ \partial \xi }{ \partial t } + \frac{ \partial (nv) }{ \partial \xi } \frac{ \partial \xi }{ \partial x }  = 0  \\[.8em]
\implies & -M\frac{ \partial n }{ \partial \xi }  + \frac{ \partial (nv) }{ \partial \xi } = 0 
\end{align}
$$
- $(B)$ 
$$
-M \frac{ \partial v }{ \partial \xi }  + v \frac{ \partial v }{ \partial \xi } = - \frac{ \partial \phi}{ \partial \xi }  
$$
- $(C)$ 
$$
- \frac{ \partial^2 \phi }{ \partial \xi^2 } = n - \exp (\phi) 
$$
