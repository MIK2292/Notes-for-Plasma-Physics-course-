# Solitons
Solutions in the form of solitons waves
(circa pacchetto d'onda gaussiana)
pic01 -  soliton

with 
$$
M= \frac{v_{0}}{c}, \ \ \ \ \xi = x - Mt
$$
and bound condition for $\xi \to \infty$ (with $()' \to \frac{d}{dt}$)
$$
\begin{align}
\phi' = 0, && \phi = 0 \\[.6em]
v'=0, && v=0 \\[.6em]
n'=0, && n=1
\end{align}
$$
$$
\begin{cases}
-M\dfrac{ \partial n }{ \partial \xi }  + \dfrac{ \partial (nv) }{ \partial \xi } = 0 &(A) \\[.8em]
-M \dfrac{ \partial v }{ \partial \xi }  + v \dfrac{ \partial v }{ \partial \xi } = - \dfrac{ \partial \phi}{ \partial \xi }  &(B) \\[.8em]
- \dfrac{ \partial^2 \phi }{ \partial \xi^2 } = n - \exp (\phi)  &(C)
\end{cases}
$$
From $(A)$ (using also the boundary conditions)
$$
\begin{align}
&\frac{ \partial  }{ \partial \xi } \left[ n\left( v-M \right)  \right] = 0 \\[.6em]
 \implies& nv - nM = \text{const} \stackrel{\xi\to \infty}{\longrightarrow} -M \\[.6em]
\implies& n= \frac{M}{M-v}
 \end{align}
$$
From $(B)$ 
$$
\begin{align}
&\frac{ \partial }{ \partial \xi } \left[ - Mv + \frac{v^2}{2} + \phi \right] = 0 \\[.6em]
\implies& - Mv + \frac{v^2}{2} + \phi = \text{const} \stackrel{\xi\to \infty}{\longrightarrow} 0 \\[.6em]
\implies& v^2 - 2Mv  + 2\phi =  0 \\[.6em]
\implies& \left( M-v \right)^2 -M^2   + 2\phi =  0 \\[.6em]
\implies& \left( M-v \right) = \pm \sqrt{ M^2   - 2\phi} 
\end{align}
$$
We only take the positive solution, since the negative one gives imaginary solutions
We use the result from $(A)$ 
$$
\implies n = \frac{M}{\sqrt{ M^2 - 2\phi }}
$$
and now, substituting in $(C)$ 
(we use $\phi''$ to indicate $(\partial^2 \phi / \partial \xi^2)$)
$$
\begin{align}
&- \phi'' = n - \exp (\phi) \\[.8em]
\implies & - \phi'' = \frac{M}{\sqrt{ M^2 - 2\phi }} - \exp (\phi) \\[.8em]
\implies & - \phi'\phi'' = \frac{M\phi'}{\sqrt{ M^2 - 2\phi }} - \exp (\phi) \phi' \\[.8em]
\implies & - \int \phi'\phi''\, d \xi = \int \frac{M\phi'}{\sqrt{ M^2 - 2\phi }} d\xi - \int \exp (\phi) \phi'\, d\xi
\end{align}
$$
The first integral becomes 
$$
- \int \phi'\phi''\, d \xi = - \frac{1}{2} \int \frac{d}{d\xi} \phi'^2 \, d\xi = - \frac{\phi'^2}{2} 
$$
The second integral becomes
$$
M\int \frac{\phi'}{\sqrt{ M^2 - 2\phi }} d\xi = -M \sqrt{ M^2 - 2 \phi }
$$
And the third 
$$
- \int \exp (\phi) \phi'\, d\xi = - \exp (\phi)
$$
so we have
$$
\begin{align}
&- \frac{\phi'^2}{2}  = -M \sqrt{ M^2 - 2 \phi } - \exp (\phi) + \text{const} \\[.8em]
\implies \ & \frac{\phi'^2}{2}  = M \sqrt{ M^2 - 2 \phi } + \exp (\phi) + K
\end{align}
$$
we find $K$ using boundary condition $(\xi \to \infty)$ 
$$
\begin{align}
&0 = M^2 +1 +K \\[.6em]
\implies \ & K = - \left( 1+M^2 \right) 
\end{align}
$$
so
$$
\implies \frac{\phi'^2}{2}  = M \sqrt{ M^2 - 2 \phi } + \exp (\phi) - \left( 1+M^2 \right) \ \ \ \ \ \ \ \ (\text{eq. 01})
$$

^a35cf6
Now we need some asumptions: 
$$
\phi \ll 1, \ \ \ \ \ \ \ \ \ 0 < \delta M \ll 1
$$
with
$$
\delta M = M-1 = \frac{v_{0}}{c_{s}} -1
$$
the second condition tells us
$$
\begin{cases}
0<\delta M &\implies &v_{0} >c_{s} \\[.6em]
\delta M \ll 1 &\implies &v_{0} \gtrsim c_{s}
\end{cases}
$$
Also, later we will see that these two conditions are the same condition
So 
$$
M = 1 + \delta M, \ \ \ \ \ \ M^2 = 1 + 2\delta M + \delta M^2
$$
and
$$
\sqrt{ M^2 - 2 \phi } = \left( 1 + 2\delta M + \cancel{ \delta M^2 } - 2\phi \right) ^{1/2} \approx \big[ 1 - \underbrace{ 2\left( \delta M - \phi \right) }_{ h \ll 1 }  \big] ^{1/2} 
$$
and we can Taylor expand 
$$
\sqrt{ M^2 - 2 \phi } \approx 1 + \frac{h}{2} - \frac{h^2}{8} + \frac{h^3}{16} - \cdots
$$
and
$$
\exp(\phi) \approx 1 + \phi + \frac{\phi^2}{2} + \frac{\phi^3}{6} + \cdots
$$
and
$$
 1+M^2= 1 + 1 + 2\delta M + \cancel{ \delta M^2 } \approx 2 + 2\delta M
$$
Substituting into the [[2025-10-09 - Valentini (3)#^a35cf6|eq. 01]], multiplying and only keeping the terms with the following powers
$$
\delta M,\ \phi,\  \phi^2,\  \phi^3,\  \delta M \phi,  \ \delta M \phi^2
$$
we obtain
$$
\begin{align}
\frac{\phi'^2}{2}  = M \sqrt{ M^2 - 2 \phi } + \exp (\phi) - \left( 1+M^2 \right)  &&&&(\text{eq }1)
\end{align}
$$
$$
\begin{align}
\frac{\phi'^2}{2} &\approx (1+\delta M) \cdot \left[ 1+(\delta M - \phi) - \frac{1}{2} (\delta M - \phi)^2 + \frac{1}{2} (\delta M - \phi)^3 \right] + \\[.6em]
&\ \ \ \ \ \, + \left( 1 + \phi + \frac{\phi^2}{2} + \frac{\phi^3}{6} \right) + (2 + 2\delta M) \approx \\[.8em] 
&\approx - \frac{\phi^3}{2} + \frac{3}{2 } \delta M \phi^2 - \frac{\delta M \phi^2}{2} + \frac{\phi^3}{6}  \approx  \\[.8em]
&\approx - \frac{\phi^3}{3} + \delta M\phi^2
\end{align}
$$
which is non linear yet.
We rewrite it as
$$
\begin{align}
&\phi'^2 = 2 \delta M \phi^2 \left[ 1- \frac{\phi}{3\delta M} \right] \\[.8em]
\implies&\phi' = \sqrt{ 2 \delta M} \phi \left[ 1- \frac{\phi}{3\delta M} \right]^{1/2}
\end{align}
$$
where we take only the positive value of the square root.
Now we solve using separation of variables
$$
\frac{1}{\phi} \frac{d\phi}{\sqrt{ 1 - \dfrac{\phi}{3 \delta M} }} = \sqrt{  2 \delta M } d \xi
$$
and
$$
\int \frac{1}{\phi} \frac{d\phi}{\sqrt{ 1 - \frac{\phi}{3 \delta M} }} = \int \sqrt{ 2 \delta M } d \xi = \xi\sqrt{ 2 \delta M  } + K_{1}
$$
On the left side we apply two change of variables 
1) $y = \phi / 3 \delta M$,   so   $\phi = y \cdot 3 \delta M, \ \ d\phi = 3 \delta M \,dy$ 
2) $u^2 = 1-y$,     so   $y= 1-u^2, \ \ \ \ dy = -2u\,du$ 
$$
\begin{align}
\int \frac{1}{\phi} \frac{d\phi}{\sqrt{ 1 - \frac{\phi}{3 \delta M} }} &= - \int \frac{1}{y\cdot \cancel{ 3\delta M }} \frac{\cancel{ 3\delta M } \,dy}{\sqrt{ 1 - y\, }} =  \\[.8em]
 &= -2 \int \frac{du}{1-u^2} =  \\[.8em] 
 &= -2 \,\text{arctanh}\,(u) + K_{2} =  \\[.8em] 
 &= -2 \,\text{arctanh}\,\left[ \left( 1 - \frac{\phi}{3\delta M} \right) ^{1/2} \right]  + K_{2}
\end{align}
$$
so we have
$$
\begin{align}
&-2 \,\text{arctanh}\,\left[ \left( 1 - \frac{\phi}{3\delta M} \right) ^{1/2} \right]  + K_{2} = \xi\sqrt{  2\delta M } + K_{1} \\[.8em]
\implies& -2 \,\text{arctanh}\,\left[ \left( 1 - \frac{\phi}{3\delta M} \right) ^{1/2} \right] = \xi\frac{\sqrt{ 2 \delta M }}{2} + \underbrace{ \frac{K_{1}+K_{2}}{2} }_{ K } \\[.8em]
\implies&- \sqrt{ 1 - \frac{\phi}{3 \delta M} } = \tanh \left[ \xi\sqrt{ \frac{\delta M}{2} } + K \right] \\[.8em]
\implies& \phi = 3 \delta M \left\{  1+ \tanh^2 \left[ \xi\sqrt{ \frac{\delta M}{2} }  + K \right] \right\}\\[.8em]
\implies& \phi = 3 \delta M \,\text{sech}^2\left( \xi\sqrt{ \frac{\delta M}{2} }  + K \right)
\end{align}
$$
For every $K$, $\phi \to 0$ 
So we choose $K=0$ whitout any loss of generality and
$$
\phi = 3 \delta M \,\text{sech}^2\left( \sqrt{ \frac{\delta M}{2} } \xi  \right) = 3 \delta M \,\text{sech}^2\left[ \sqrt{ \frac{\delta M}{2} } (x-Mt) \right]
$$
The maximum amplitude of $\phi$ is $3\delta M$ 
That's why 
$$
\phi \ll 1 \ \ \ \Longleftrightarrow \ \ \ \delta M \ll 1
$$
Solitons are stable waves and are more easily detectable than others
Space probes captures them
IRS -> Isolated Electrostatic Structures
they are everywhere in the magnetosphere


# Kinetik theory of plasma
Vlasov equation
$$
\frac{ \partial f_{\alpha} }{ \partial t } + \bar{v}\, \nabla f_{\alpha } + \frac{\rho_{\alpha}}{m_{\alpha}} \left[ \bar{E} + \frac{\bar{v}\times \bar{B}}{c} \right] \cdot \nabla _{\bar{v} } f_{\alpha} = 0
$$
There are different methods to obtain it 
- from Liouville equation
- using the Klimontovich derivation  (which we will study)

(we will replace the pedix $a$ with $s$, in order to follow the notation of the book)
($m$ is an index like $s$, which we will use to do a trick later)
Outline of the Klimontovich method:
1) We start from an ensemble of particles
2) We study the equations of motion
$$
\begin{cases}
\dot{\bar{x}} _{s} (t)= \bar{v}_{s} (t) \\[.8em]
\displaystyle \dot{\bar{v}} _{s} (t)= \frac{\rho_{s}}{m_{s}} \left[ \bar{E}_{m} (\bar{x},t) + \frac{\bar{v}\times \bar{B}(\bar{x},t)}{c}\right] 
\end{cases}
$$
We will use the following math instruments:
- Dirac Delta
- Redisuals Theorem
- Laplace Transform
- Green's Function
