## Total derivative of $f$
$$
\frac{d}{dt} f_{\alpha} = \frac{ \partial f_{\alpha} }{ \partial t } + \frac{ \partial f_{\alpha} }{ \partial \bar{r} } \frac{ \partial \bar{r} }{ \partial t } + \frac{ \partial f }{ \partial v } \frac{ \partial v }{ \partial t } 
$$
we use *characteristics curves*
$$
\frac{d}{dt} \bar{r} = \bar{v}, \ \ \ \frac{d}{dt} \bar{v} = \frac{q_{\alpha}}{m_{\alpha}} \left( \bar{E}  + \frac{\bar{v}\times \bar{B}}{c} \right) 
$$
and
$$
\frac{d}{dt} f_{\alpha} = \frac{ \partial f_{\alpha} }{ \partial t } + \frac{ \partial f_{\alpha} }{ \partial \bar{r} } \bar{v} + \frac{ \partial f }{ \partial v } \frac{q_{\alpha}}{m_{\alpha}} \left( \bar{E}  + \frac{\bar{v}\times \bar{B}}{c} \right)  = 0
$$
which is vlasov
$$
\left. \frac{d f_{\alpha}}{dt}  \right|_{\text{orbit}} = 0
$$
## Two fluid equations
electrostatic approximation, unmagnetized plasma
$\bar{B} = 0, \dot{\bar{B}} =0$
so
$$
\begin{align}
\frac{ \partial n_{\alpha} }{ \partial t }  + \nabla \cdot \left( n_{\alpha}\bar{U}_{\alpha} \right) &= 0 \\[0.6em]
m_{\alpha}n_{\alpha} \left[ \frac{ \partial U }{ \partial t }  + U_{\alpha} \cdot \nabla U_{\alpha} \right]& = - \nabla \cdot \stackrel{\leftrightarrow}{P_{\alpha}} + q_{\alpha} n_{\alpha} \bar{E} = - \nabla p_{\alpha} + q_{\alpha} n_{\alpha} \left( - \nabla \Phi \right) \\[0.6em]
\nabla \cdot \bar{E}& = 4 \pi \sum _{\alpha} q_{\alpha} n_{\alpha} \\[0.6em]
\nabla \cdot \bar{B} &= 0 \\[0.6em]
\nabla \times \bar{E}& = - \frac{1}{c} \frac{ \partial B }{ \partial t }  = 0 \\[0.6em] 
\nabla \times \bar{B}& = \frac{4\pi}{c} \sum_{\alpha} q_{\alpha}n_{\alpha}\bar{U}_{\alpha} + \frac{1}{c} \frac{ \partial E }{ \partial t }  = 0 
\end{align}
$$
in our case
$$
- \nabla \stackrel{\leftrightarrow}{P_{\alpha}} \ \ \to \ \   - \nabla p_{a}
$$
with (ideal gas hypothesys)
$$
p_{\alpha} = n_{\alpha} k_{B}T_{\alpha}
$$
since
$$
\nabla \times \bar{E} = 0 \implies \bar{E} = - \nabla \Phi
$$
we eliminate one redundant equation
$$
\begin{align} 
&\nabla \times \bar{B} = \frac{4\pi}{c} \sum_{\alpha} q_{\alpha}n_{\alpha}\bar{U}_{\alpha} + \frac{1}{c} \frac{ \partial E }{ \partial t } = 0 \\[.6em]
\implies \ & \nabla \cdot \left( \frac{4\pi}{c} \sum_{\alpha} q_{\alpha}n_{\alpha}\bar{U}_{\alpha} + \frac{1}{c} \frac{ \partial E }{ \partial t } \right)  = 0 \\[0.6em]
 \implies \ & \frac{ \partial  }{ \partial t } \nabla \cdot \bar{E} + 4 \pi \sum_{\alpha} q_{\alpha} \nabla \cdot \left( n_{\alpha} \bar{U}_{ \alpha} \right)  = 0  
\end{align}
$$
Now we use continuity equation and
$$
\begin{align}
& \ \implies \frac{ \partial  }{ \partial t } \nabla \cdot \bar{E} + 4 \pi \sum_{\alpha} q_{\alpha} \left( - \frac{ \partial n_{\alpha} }{ \partial t }  \right)   = 0 \\[0.6em]
& \ \implies \frac{ \partial  }{ \partial t } \left( \nabla \cdot \bar{E} - 4\pi \sum_{\alpha} q_{\alpha} n_{\alpha} \right)   = 0 \\[0.6em]
& \ \implies  \nabla \cdot \bar{E} - 4\pi \sum_{\alpha} q_{\alpha} n_{\alpha}   = K = 0
\end{align}
$$
which does not have a time derivative and it's easier to use.
we say $K=0$ its the only possible choice from poisson equation.
(eg. a 1D solution in a neutral space for $\nabla \cdot \bar{E}= K \neq 0$ is $\bar{E}(x) = Kx$, which diverges at infinity).

In the end we have the following set of equations
$$
\begin{align}
\frac{ \partial n_{\alpha} }{ \partial t }  + \nabla \cdot \left( n_{\alpha}\bar{U}_{\alpha} \right) &= 0 \\[0.6em]
m_{\alpha}n_{\alpha} \left[ \frac{ \partial \bar{U}}{ \partial t }  + \bar{U}_{\alpha} \cdot \nabla \bar{U}_{\alpha} \right]& = - \nabla p_{\alpha} + q_{\alpha} n_{\alpha} \left( - \nabla \Phi \right) \\[0.6em]
- \nabla^2 \Phi& = 4 \pi \sum _{\alpha} q_{\alpha} n_{\alpha} \\[0.6em]
p_{\alpha} &= n_{\alpha}k_{B}T_{\alpha}
\end{align}
$$
