# Quasi linear theory 
We begin form the Vlasov-Poisson system
$$
 \begin{cases}
\displaystyle\frac{ \partial f (x,v,t)}{ \partial t }  + v \frac{ \partial f (x,v,t) }{ \partial x }  - \frac{eE(x,t)}{m_{e}} \frac{ \partial f (x,v,t) }{ \partial v } = 0 \\[.8em]
\displaystyle \frac{ \partial E(x,t) }{ \partial x }  = 4\pi e  \left[  n_{0} - \int_{-\infty}^{\infty} f(x,v,t) \, dv  \right] 
\end{cases}
$$
Where we define the distribution function and the electric field as
$$
\begin{align}
&f(x,v,t) = f_{0} (v) + f_{1}(x,v,t), && \text{with }\  f_{1}(x,v,t) = \sum_{k} f_{k} (v,t) e^{ ikx } \\[1em]
&E(x,t) = E_{1} (x,t), && \text{with } \ E_{1}(x,t) = \sum_{k} E_{k}  (t) e^{ ikx }
\end{align}
$$
we also recall that 
$$
 \begin{align}
\langle f_{1}(x,v,t) \rangle = \langle E_{1}(x,t) \rangle = 0
\end{align}
$$
with the averages carried out in the physical space
$$
 \langle \dots \rangle = \frac{1}{L} \int_{0}^L (\dots) \, dx
$$
We want to allow the velocity distribution to be disturbed in the velocity space significantly. 
We consider $f(v,t)$, so we make it vary in time
$$
\begin{align}
 f(x,v,t) &= \cancel{ f_{0}(v ) + f_{1}(x,v,t) }  \\[.8em]
&= f_{0}(v,t ) + f_{1}(x,v,t)
\end{align}
$$
so, as a consequence, we get 
$$
 \langle  f_{1} (x,v,t) \rangle  = f_{0}(v,t) 
$$
Now we take the average value of the Vlasov equation
$$
\begin{align}
&\frac{ \partial  }{ \partial t } \langle f \rangle + \cancel{ v \left\langle   \frac{ \partial f }{ \partial x }   \right\rangle } - \cancel{ \frac{e}{m} \left\langle   E_{1} \frac{ \partial f_{0} }{ \partial v }   \right\rangle } - \frac{e}{m} \frac{ \partial  }{ \partial v } \langle  E_{1} f_{1} \rangle  = 0 \\[.8em]
\implies & \frac{ \partial  }{ \partial t } \langle f \rangle = \frac{e}{m} \frac{ \partial  }{ \partial v } \langle  E_{1} f_{1} \rangle  
\end{align}
$$
We consider the following term 
$$
 \langle  E_{1} f_{1} \rangle  = \frac{1}{L} \int_{0}^L \sum_{k'} \sum_{k} E_{k'}(t) f_{k}(v,t) e^{ i(k'-k)x } \, dx
$$
which is different from zero only for $k'=k$, so 
$$
\begin{align}
& \langle  E_{1} f_{1} \rangle  = \sum_{k} E_{-k}(t) f_{k}(v,t)   \\[.8em]
\implies& \frac{ \partial  }{ \partial t } \langle  f \rangle  = \frac{e}{m} \frac{ \partial  }{ \partial v } \sum_{k} E_{-k}(t) f_{k}(v,t) 
\end{align}
$$
Now we use the linear Landau result to obtain a first perturbative nonlinear result. 
$$
 E_{1}(x,t) = \sum_{k} E_{k} (t) e^{ ikx } = \sum_{k} E_{k}(0) e^{ -i\omega_{I}t } e^{ ikx }
$$
Later we will use the following notation
$$
 \omega_{k} = \omega_{R,k} + \omega_{I, k } 
$$
We will use the Green's function.
We move to the Fourier space 
$$
\frac{ \partial  }{ \partial t } f_{k}(v,t) + ikv f_{k}(v,t) - \frac{e}{m} E_{k}(t) \frac{ \partial f_{0} }{ \partial v } = 0
$$

# Renormalization theory
We know that we can approximate the Dirac delta using the following formulation
$$
 \mathbb{R} = \frac{\Delta \omega}{(kv - \omega_{k})^2 + \Delta \omega^2} \longrightarrow \delta
$$
$$
 \frac{ \partial f_{0} }{ \partial t } = \frac{ \partial }{ \partial v } \left[ \frac{e^2}{m^2} \sum_{k} \lvert  E_{k}(t) \rvert ^2 \frac{\Delta \omega}{(kv - \omega_{k})^2 + \Delta \omega^2} \frac{ \partial f_{0} }{ \partial v }  \right] 
$$
This formula tells us how $f_{0}$ evolves in time. This time dependency of $f_{0}$ happens mostly in the resonant region (because at the denominator we have $kv-\omega_{k}$).
We approximate this result close to $v_{\phi}$ 
$$
 \frac{ \partial }{ \partial t } f(v \approx v_{\phi}, t) = \frac{ \partial }{ \partial v } \left[ \frac{e^2}{m^2} \sum_{k} \lvert  E_{k}(t) \rvert ^2 \frac{1}{\Delta \omega} \frac{ \partial f_{0} }{ \partial v }  \right] 
$$
and we can rewrite this equation as
$$
\begin{align}
 \frac{ \partial f_{0} }{ \partial t } - \frac{e^2}{m^2} \frac{\sum_{k}\lvert E_{k}(t) \rvert ^2}{\Delta \omega} \frac{ \partial^2 f_{0} }{ \partial v^2 } = 0 &&\implies&& \frac{ \partial f_{0} }{ \partial t }  - D \frac{ \partial^2 f_{0} }{ \partial v^2 } = 0 
\end{align}
$$
This is the velocity diffusion equation (similar to the heat equation in velocity space).

$$
