1 dimensional vlasov
$$
\frac{ \partial f(x,v,t) }{ \partial t } + v \frac{ \partial f(x,v,t) }{ \partial x } - \frac{eE}{m_{e}} \frac{ \partial f(x,v,t) }{ \partial v } = 0
$$
Poisson
$$
\frac{ \partial E(x,t) }{ \partial x }  = 4\pi e \left[ n_{0} - \int_{-\infty}^{\infty} f(x,v,t) \, dv  \right]
$$
linearize vlasov
$$
\frac{ \partial f_{1} }{ \partial t } + v \frac{ \partial f_{1} }{ \partial x } - \frac{eE_{1}}{m_{e}} \frac{ \partial f_{0} }{ \partial v } = 0
$$
and (considering $\lvert \omega_{I} / \omega_{R} \rvert \ll 1$)
$$
\begin{align}
E_{1}(x,t) &= E_{0} e^{ \omega_{I} t } \sin (kx-\omega_{R}t) \approx E_{0} \sin (kx-\omega_{R}t) \\[.8em]
f_{1}(x,v,t) &= f_{0}(v) \beta_{k} \cos(kx-kvt) + \frac{eE_{0}}{m_{e}} \frac{ \partial f_{0} }{ \partial v } \left[ \frac{\cos(kx - \omega_{R}t) - \cos (kx - kvt)}{\omega_{R}-kv} \right]
\end{align}
$$
with 
$$
\begin{cases}
\beta_{k} = -\dfrac{t_{0}k}{4\pi en_{0}} \\[.8em]
f_{0} = \dfrac{m_{e}^{1/2} n_{0}}{(2\pi k_{B}T_{0})^{1/2}} \exp \left( -\dfrac{mv^2}{2k_{B}T_{0}} \right)
\end{cases}
$$
At time $\tau$ we have
$$
 \left\lvert  \frac{ \partial f_{0} }{ \partial v }   \right\rvert  \approx \left\lvert  \frac{ \partial f_{1} }{ \partial v }   \right\rvert 
$$
we want to compare them 
If they are comparable, then linear approximation fails. 

The main effects happens in the resonant region

We taylor expand the expression of $f_{1}$ in $v= \omega_{R} / k$.
In particular we take care of the square brakets
$$
\begin{align}
 &\cos(kx - \omega_{R}t) - \cos (kx - kvt) \approx \cos(kx - \omega_{R}t) - \bigg[ \cos\left( kx - k \frac{\omega_{R}}{k}t \right) + \\[.6em]
&\ \ \ \ \ \ + kt \sin \left(kx - k \frac{\omega_{R}}{k}t\right) \left( v-\frac{\omega_{R}}{k} \right) + \frac{1}{2} k^2 t^2 \cos\left(kx - k \frac{\omega_{R}}{k}t\right) \left( v-\frac{\omega_{R}}{k} \right)^2 +\dots \bigg] \approx  \\[.8em]
&\ \approx -kt \sin \left(kx - \omega_{R}t\right) \left( v-\frac{\omega_{R}}{k} \right) - \frac{1}{2} k^2 t^2 \cos\left(kx - \omega_{R}t\right) \left( v-\frac{\omega_{R}}{k} \right)^2  
\end{align}
$$
Now we substitute
$$
\begin{align}
 f_{1}(x,v,t) &= f_{0}(v) \beta_{k} \cos(kx-kvt) + \frac{eE_{0}}{m_{e}} \frac{ \partial f_{0} }{ \partial v } \cdot \\[.8em]
&\ \ \ \ \ \cdot\left[ \frac{-\cancel{ k }t \sin \left(kx - \omega_{R}t\right) \cancel{ \left( v-\frac{\omega_{R}}{k} \right) } - \frac{1}{2} k^\cancel{ 2 } t^2 \cos\left(kx - \omega_{R}t\right) \left( v-\frac{\omega_{R}}{k} \right)^\cancel{ 2 }}{-\cancel{ k }\cancel{ \left( v-\frac{\omega_{R}}{k} \right) }} \right] =  \\[.8em]
&= f_{0}(v) \beta_{k} \cos(kx-kvt) + \frac{eE_{0}}{m_{e}} \frac{ \partial f_{0} }{ \partial v } \cdot \\[.8em]
&\ \ \ \ \ \cdot\left[ t \sin \left(kx - \omega_{R}t\right) + \frac{1}{2} k t^2 \cos\left(kx - \omega_{R}t\right) \left( v-\frac{\omega_{R}}{k} \right) \right]

\end{align}
$$
We want to find the derivative of $f_{1}$ 
$$
\begin{align}
 \frac{ \partial f_{1} }{ \partial v } & = \frac{ \partial f_{0} }{ \partial v } \beta_{k} \cos(kx-kvt) + f_{0} \beta_{k} kt\sin(kx-kvt) + \frac{eE_{0}}{m_{e}} \frac{d^2f_{0}}{dv^2} \cdot  \\[.8em]
 & \ \ \ \ \ \ \cdot \left[ t \sin \left(kx - \omega_{R}t\right) + \frac{1}{2} k t^2 \cos\left(kx - \omega_{R}t\right) \left( v-\frac{\omega_{R}}{k} \right) \right] +  \\[.8em]
& \ \ \ \ \ \ + \frac{eE_{0}}{m_{e}} \frac{df_{0}}{dv} \left[ -\frac{1}{2} kt^2 \cos \left(kx - \omega_{R}t\right) \right] 
\end{align}
$$
The terms which goes like $t^2$ are prevalent for large $t$ ($t \to \infty$).
However, the term ($v- \omega_{R} / k$) is small because we are very close to the pole, so the dominant term for $t \to \infty$ is the last one.
So 
$$
 \left| \frac{df_{0}}{dv} \right|  \approx \frac{eE_{0}}{m_{e}} \frac{df_{0}}{dv} \frac{1}{2} kt^2 \ \ \ \implies \ \ \ 1 \approx \frac{eE_{0}}{m_{e}} \frac{1}{2} kt^2
$$
(indeed the cosine oscillates and we can approximate it to $1$)
From the last expression we can define the **trapping time** 
$$
 \tau \equiv \sqrt{ \frac{m_{e}}{eE_{0}k} }
$$
At the trapping time, the linear approximation is not valid anymore.

# Energetics of wave-particle resonant interaction
Is the energy conserved? To prove it, we assume that it is conserved.
The energy balance is the following, with $K$ kinetik energy of the particles and $W$ wave energy
$$
 \frac{dK}{dt}  = -\frac{dW}{dt} 
$$
Kinetik energy density
$$
 K = \frac{m_{e}}{2} \int_{-\infty}^{\infty} v^2 f_{1}(x,v,t) \, dv 
$$
recalling 
$$
 \frac{d}{dt}  (vf_{0}) = 0
$$
Using the greek letter "$\kappa$" to indicate 
$$
 \kappa = \frac{m_{e}}{2} \frac{1}{\lambda} \int_{-\lambda/2}^{\lambda / 2} \, dx \int_{-\infty}^{\infty} v^2 f_{1}(x,v,t) \, dv 
$$
with $\lambda= 2\pi / k$ being the wavelenght of the perturbation. 
$$
 \frac{d}{dt}  \kappa = \frac{m_{e}}{2} \frac{1}{\lambda} \int_{-\lambda/2}^{\lambda / 2} \, dx \int_{-\infty}^{\infty}  v^2 \frac{ \partial  }{ \partial t }  f_{1}(x,v,t) \, dv 
$$
We use a galileian transformation to move in the Wave Reference Frame
$$
 \begin{align}
v'= v-\frac{\omega_{R}}{k}, && x' = x - \frac{\omega_{R}}{k}t, &&t'=t
\end{align}
$$
we have
$$
 \frac{d}{dt}  \kappa = \frac{m_{e}}{2} \frac{1}{\lambda} \int_{-\lambda/2}^{\lambda / 2} \, dx' \int_{-\infty}^{\infty}  \left( v'-\frac{\omega_{R}}{k} \right)^2 \frac{ \partial  }{ \partial t' }  f'_{1}(x',v',t') \, dv 
$$

$$
\begin{align}
 f'_{1}(x',v',t') &= f_{0} (v') \beta_{k} \cos \left[ k \left( x' + \cancel{ \frac{\omega_{R}}{k}t' } \right) - k \left( v' + \cancel{ \frac{\omega_{R}}{k} } \right)t' \right] + \frac{eE_{0}}{m_{e}} \frac{ \partial f_{0}(v') }{ \partial v' } \cdot \\[.8em]
& \ \ \ \ \ \cdot \frac{1}{\cancel{ \omega_{R} } - k \left( v' + \cancel{ \dfrac{\omega_{R}}{k} } \right) } \bigg\{ \cos \left[ k \left( x' + \frac{\omega_{R}}{k}t' \right) - \omega_{R}t' \right] + \\[.8em]
&\ \ \ \ \ \ - \cos \left[ k \left( x' + \cancel{ \frac{\omega_{R}}{k}t' } \right) - k \left( v' + \cancel{ \frac{\omega_{R}}{k} } \right)t' \right]   \bigg\} = \\[.8em]
 &= f_{0} (v') \beta_{k} \cos \left( kx' - kv't' \right) + \frac{eE_{0}}{m_{e}} \frac{ \partial f_{0}(v') }{ \partial v' } \left\{ \frac{\cos(kx')- \cos (kx' - kv't')}{-kv'} \right\} 
\end{align}
$$
Now in order to have an easier notation we change the primed variables to unprimed variables.
We apply the averages
$$
 \frac{ \partial  }{ \partial t } \langle f_{1} (x,v,t) \rangle = \frac{1}{\lambda} \int_{-\lambda/2}^{\lambda / 2}  \frac{ \partial  }{ \partial t }  f(x,v,t) \, dx
$$
In total linear approximation of the Vlasov equation we obtain $0=0$, so we need to consider at least the first nonlinear term 
$$
\begin{align}
&\frac{ \partial }{ \partial t } \langle f_{1} \rangle + v \cancel{ \left\langle  \frac{ \partial r }{ \partial  } f_{1}   \right\rangle } - \cancel{ \frac{e}{m_{e}} \langle E_{1} \rangle \frac{ \partial f_{0} }{ \partial v }  } - \frac{e}{m_{e}} \left\langle E_{1} \frac{ \partial f_{1} }{ \partial v } \right\rangle = 0   \\[.8em]
\implies & \frac{ \partial }{ \partial t } \langle f_{1} \rangle = \frac{e}{m_{e}} \frac{ \partial  }{ \partial v }\left\langle E_{1} f_{1}  \right\rangle 
\end{align}
$$
So an increase in the kinetik energy is nonlinear effect 
$$
 \frac{ \partial }{ \partial t } \langle f_{1} \rangle = \frac{e}{m_{e}}  E_{0} \left\langle \sin kx \cdot \frac{ \partial f_{1} }{ \partial v } \right\rangle
$$
$$
\begin{align}
 \frac{d}{dt} \kappa &= \frac{m_{e}}{2} \int_{-\infty}^{\infty} \left( v-\frac{\omega_{R}}{k} \right)^2 \frac{eE_{0}}{m_{e}}   \left\langle \sin kx \cdot \frac{ \partial f_{1} }{ \partial v } \right\rangle \, dv =  \\[.8em]
  &= \frac{m_{e}}{2} \bigg[ \left. \left( v-\frac{\omega_{R}}{k} \right)^2 \frac{eE_{0}}{m_{e}}   \left\langle \sin kx \cdot  f_{1} \right\rangle \right|_{-\infty}^{+\infty} - \int_{-\infty}^{\infty} 2 \left( v-\frac{\omega_{R}}{k} \right) \frac{eE_{0}}{m_{e}}   \left\langle \sin kx \cdot f_{1}  \right\rangle \, dv \bigg] 
\end{align}
$$
Considering that $f_{1}$ goes to zero for $v$ which goes to infinity 
$$
f_{1} (x,v\to \pm\infty,t) \to 0
$$
and simplifying the factor $m_{e} / 2$, we get 
$$
\begin{align}
 \frac{d}{dt} \kappa &=- eE_{0} \int_{-\infty}^{\infty}  \left( v-\frac{\omega_{R}}{k} \right) \left\langle \sin kx \cdot f_{1}  \right\rangle \, dv 
\end{align}
$$
From this expression two integrals come out.
The first integral is 
$$
 \frac{1}{\lambda} \int_{-\lambda /2} ^{\lambda /2} \sin (kx) \cos (kx) \, dx = \frac{1}{\lambda} \int_{-\lambda /2} ^{\lambda /2}\sin (kx ) \, d(\sin (kx)) = \left. \frac{\sin^2 (kx)}{2} \cdot \frac{k}{2\pi} \right|_{-\pi /2}^{\pi / 2} = 0
$$
The second integral is (recalling that $\lambda = 2\pi / k$)
$$
\begin{align}
\frac{1}{\lambda} \int_{-\lambda /2} ^{\lambda /2}& \sin (kx) \cos (kx - kvt) \, dx =  \\[.8em]
&=\frac{1}{\lambda} \int_{-\lambda /2} ^{\lambda /2} \sin (kx) \left\{ \cancel{ \cos(kx)\cos(kvt) } + \sin(kx)\sin(kvt) \right\}  \, dx = \\[.8em]
&= \frac{1}{\lambda} \sin (kvt) \int_{-\lambda /2} ^{\lambda /2} \sin(kx) \sin(kx) \, dx =  \\[.8em]
&= \frac{\sin (kvt)}{2}
\end{align}
$$
So 
$$
\begin{align}
 \frac{d}{dt} \kappa &= - eE_{0} \int_{-\infty}^{\infty}  \left( v-\frac{\omega_{R}}{k} \right) \left\langle \sin kx \cdot f_{1}  \right\rangle \, dv  = \\[.8em]
&= - eE_{0} \int_{-\infty}^{\infty}  \left( v-\frac{\omega_{R}}{k} \right) \left\{ f_{0} (v) \beta_{k} \frac{\sin(kvt)}{2} + \frac{eE_{0}}{m_{e}} \frac{ \partial f_{0} }{ \partial v } \frac{\sin(kvt)}{2kv}  \right\}  \, dv 
\end{align}
$$
Which is the resonant function (what?)
We will need the following definition of the Dirac delta
$$
 \delta(x) = \lim_{ \varepsilon \to 0 } \frac{1}{\pi x} \sin\left( \frac{x}{\varepsilon} \right)
$$
so
$$
 \lim_{ t \to \infty } \frac{\sin(kvt)}{kv} \approx \pi \delta(kv)
$$
We can rewrite the first term as 
$$
 \int_{-\infty}^{\infty} \left( v-\frac{\omega_{R}}{k} \right) f_{0} (v) \beta_{k} \frac{kv}{2} \pi \delta(kv) \, dv = 0 
$$
this term is zero because the delta is different from zero for $kv = 0$, but in this point the function which multiplies the delta is null.
Now we recall the following property of the Dirac delta
$$
 \delta (Ax) = \frac{1}{\lvert  A \rvert }\delta(x)
$$
The second term is 
$$
 -\frac{e^2E_{0}^2}{2m_{e}} \int_{-\infty}^{\infty} \left( v+\frac{\omega_{R}}{k} \right) \frac{ \partial f_{0} }{ \partial v } \pi \delta (kv)  \, dv  =  -\frac{e^2E_{0}^2}{2m_{e}} \int_{-\infty}^{\infty} \left( v+\frac{\omega_{R}}{k} \right) \frac{ \partial f_{0} }{ \partial v } \frac{\pi}{k} \delta (v)  \, dv 
$$
So, in the wave reference frame, we have
$$
 \frac{d}{dt} \kappa = \left. -\frac{e^2E_{0}^2}{2m_{e}} \frac{\pi}{k}\left( v+\frac{\omega_{R}}{k} \right) \frac{ \partial f_{0} }{ \partial v } \right|_{v=0}
$$
Resonant function
PIC RF


We see the main contribution close to $v=0$, which is the resonant region of the wave.

Now we have a look at 
$$
 \frac{d}{dt}  W
$$
This time we have 
$$
 E_{1}(x,t) = E_{0} \sin (kx) \exp (\omega_{I}t)
$$
The energy density associated to an electric wave (in cgs) is 
$$
\begin{align}
 W &= \frac{E_{1}^2}{4\pi}=  \\[.8em]
&= E_{0}^2 \frac{e^{2\omega_{I}t}}{4\pi} \frac{1}{\lambda} \int_{-\lambda /2}^{\lambda /2} \sin^2 (kx) \, dx =  \\[.8em]
&= E_{0}^2 \frac{e^{2\omega_{I}t}}{4\pi} \frac{k}{2\pi} \frac{1}{k} \int_{-\pi /4}^{\pi /4} \sin^2 (kx) \, d(kx) =  \\[.8em]
&= E_{0}^2 \frac{e^{2\omega_{I}t}}{4\pi}  \int_{-\pi}^{\pi} \sin^2 (y) \, dy =  \\[.8em]
&= E_{0}^2 \frac{e^{2\omega_{I}t}}{4\pi}  \left. \frac{1}{2} \left[ y-\sin y \cos y \right]   \right|_{-\pi}^{\pi} =  \\[.8em]
&= \frac{E_{0}^2 e^{2\omega_{I}t}}{8\pi} 
 
\end{align}
$$
(si è mangiato un $1/k$ quando introduce $y$) 
$$
 \frac{d}{dt}  W = \frac{E_{0}^2}{8\pi } 2 \omega_{I} e^{ 2\omega_{I} t } \simeq \frac{E_{0}^2}{4\pi} \omega_{I}
$$
so
$$
 \frac{dK}{dt}  = -\frac{dW}{dt} \ \ \ \  \implies\ \ \ \ \left. -\frac{e^2E_{0}^2}{2m_{e}} \pi\frac{\omega_{R}}{k^2} \frac{ \partial f_{0} }{ \partial v } \right|_{v=0} = -\frac{E_{0}^2}{4\pi} \omega_{I}
$$
from which it follows that 
$$
 \omega_{I} = \frac{4\pi e^2}{m_{e} } \frac{\pi}{2} \frac{\omega_{R}}{k^2} \left. \frac{ \partial f_{0} }{ \partial v }   \right|_{v=0} \cdot \frac{n_{0}}{n_{0}} = \omega_{pe}^2 \frac{\pi}{2} \frac{\omega_{R}}{n_{0}k^2} \left. \frac{ \partial f_{0} }{ \partial v }  \right|_{v=0}
$$
and, in the laboratory frame, we have
$$
\omega_{I}^ {(\text{LAB})} = \omega_{pe}^2 \frac{\pi}{2} \frac{\omega_{R}}{n_{0}k^2} \left. \frac{ \partial f_{0} }{ \partial v }  \right|_{v=v_{\phi}}
$$
which is the Landau result.
