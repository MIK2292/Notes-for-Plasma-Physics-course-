Recap
$$
 D(k,\omega) = 1- \sum_{\alpha} \frac{\omega_{p, \alpha}^2}{k^2 n_{\alpha 0}} \int_{L} \frac{\partial F_{\alpha 0} (u) / \partial u}{u - \omega /k} \, du = 0
$$
$$
F_{\alpha 0} (u) = \int_{-\infty}^{\infty} f_{\alpha 0} (u,w_{1},w_{2}) \, dw_{1} \, dw_{2}
$$
$$
\begin{align}
&f_{\alpha 0} (u, w_{1}, w_{2}) = \frac{n_{\alpha 0}m_{\alpha}^{3/2}}{\left( 2\pi k_{B}T_{\alpha 0} \right) ^{3/2}} \exp \left[ - \frac{m_{\alpha}}{2 k_{B}T_{\alpha 0}} (u^2 + w_{1}^2 + w_{2}^2) \right] \\[.8em]
\implies & F_{\alpha 0} (u) = \int f_{\alpha 0} \, dw_{1} \, dw_{2} =  \frac{n_{\alpha 0}m_{\alpha}^{1/2}}{\left( 2\pi k_{B}T_{\alpha 0} \right) ^{1/2}} \exp \left[ - \frac{m_{\alpha}}{2 k_{B}T_{\alpha 0}} u^2  \right]
\end{align}
$$
$$
\left\lvert  \frac{\omega_{I}}{\omega_{R}}  \right\rvert \ll 1 \implies
\begin{cases}
D_{R}(k,\omega_{R}) = 0 \implies \omega_{R} = \omega_{R} (k) \\[.8em]
\omega_{I} = - \dfrac{D_{I}(k,\omega_{R})}{\partial D_{R} / \partial \omega_{R}}
\end{cases}
$$
with 
$$
\begin{align}
D_{R} &= 1- \sum_{\alpha} \frac{\omega_{p, \alpha}^2}{k^2 n_{\alpha 0}} \cdot P \int_{-\infty}^{\infty} \frac{\partial F_{\alpha 0} (u) / \partial u}{u - \omega_{R} /k} \, du \\[.8em]
D_{I} &= -\pi\sum_{\alpha} \frac{\omega_{p, \alpha}^2}{k^2 n_{\alpha 0}} \cdot  \left. \frac{ \partial F_{\alpha 0}(u) }{ \partial u }  \right|_{\omega_{R} / k}
\end{align}
$$
## High frequency regime
$$
\frac{\omega_{R}}{k} \gg v_{th,\alpha}
$$

The approximation is valid for the majority of the particles, except for a small fraction of particles in the tail of the distribution.
$$
\begin{align}
D_{R} &= 1- \sum_{\alpha} \frac{\omega_{p, \alpha}^2}{k^2 n_{\alpha 0}} \cdot P \int_{-\infty}^{\infty} \frac{\partial F_{\alpha 0} (u) / \partial u}{u - \omega_{R} /k} \, du  = \\[.8em]
&= 1+ \sum_{\alpha} \frac{\omega_{p, \alpha}^2}{k^2 n_{\alpha 0}} \cdot P \int_{-\infty}^{\infty} \frac{k}{\omega_{R}}\frac{\partial F_{\alpha 0} (u) / \partial u}{1 - \frac{uk}{\omega_{R}}} \, du
\end{align}
$$
we expand the integral using Taylor series
$$
P \int_{-\infty}^{\infty} \frac{k}{\omega_{R}}\frac{\partial F_{\alpha 0} (u) / \partial u}{1 - \frac{uk}{\omega_{R}}} \, du \approx \frac{k}{\omega_{R}} \int_{-\infty}^{\infty} \frac{ \partial F_{\alpha 0} }{ \partial u } \left[ 1 + \frac{uk}{\omega_{R}} + \frac{u^2k^2}{\omega_{R}^2} + \frac{u^3k^3}{\omega_{R}^3} + \dots \right] \, du = (*)
$$
and we substitute $\partial F_{\alpha 0} / \partial u$ with the definition of $F_{\alpha 0}$ for a maxwellian distribution
$$
\begin{align}
(*) &= \frac{k}{\omega_{R}} \int_{-\infty}^{\infty} \left[ \frac{n_{\alpha 0}m_{\alpha}^{1/2}}{\left( 2\pi k_{B}T_{\alpha 0} \right) ^{1/2}} \left( -\frac{m_{\alpha}}{k_{B}T_{\alpha 0}}u \right)  \exp \left( - \frac{m_{\alpha}}{2 k_{B}T_{\alpha 0}} u^2  \right) \right] \cdot  \\[.8em]
& \ \ \ \ \ \cdot\left[ 1 + \frac{uk}{\omega_{R}} + \frac{u^2k^2}{\omega_{R}^2} +  \frac{u^3k^3}{\omega_{R}^3} + \dots \right] \, du= \\[.8em]
&= - \frac{n_{\alpha 0}m_{\alpha}^{3/2}}{ \sqrt{ 2\pi }  \left( k_{B}T_{\alpha 0} \right) ^{3/2}}  \int_{-\infty}^{\infty} \exp \left( - \frac{m_{\alpha}}{2 k_{B}T_{\alpha 0}} u^2  \right) \cdot  \\[.8em]
& \ \ \ \ \ \cdot\left[ \cancel{ \frac{uk}{\omega_{R}} } + \frac{u^2k^2}{\omega_{R}^2} + \cancel{  \frac{u^3k^3}{\omega_{R}^3}  }+ \frac{u^4k^4}{\omega_{R}^4} + \dots \right] = \\[.8em]
&= - \frac{n_{\alpha 0}m_{\alpha}^{3/2}}{ \sqrt{ 2\pi }  \left( k_{B}T_{\alpha 0} \right) ^{3/2}} \left[ \frac{k^2}{\omega_{R}^2}  \int_{-\infty}^{\infty} u^2 \exp \left( - \frac{m_{\alpha}}{2 k_{B}T_{\alpha 0}} u^2  \right) \, du \right. +  \\[.8em]
  &\ \ \ \ \ + \left. \frac{k^4}{\omega_{R}^4}  \int_{-\infty}^{\infty} u^4 \exp \left( - \frac{m_{\alpha}}{2 k_{B}T_{\alpha 0}} u^2  \right) \, du \right] =(*)
\end{align} 
$$
Where all the odd functions integrated in this (symmetric) integration interval gives zero as a result.
Now we change variable using
$$
 y^2 = u^2\frac{m_{\alpha}}{2k_{B}T_{ \alpha 0}}, \ \ \ \ \ \ \ y = u \sqrt{ \frac{m_{\alpha}}{2k_{B}T_{\alpha 0}} }
$$
so we have 
$$
\begin{align}
 (*) &= - \frac{n_{\alpha 0}m_{\alpha}^{3/2}}{ \sqrt{ 2\pi }  \left( k_{B}T_{\alpha 0} \right) ^{3/2}} \left[ \frac{k^2}{\omega_{R}^2}  \int_{-\infty}^{\infty} y^2 \frac{2k_{B}T_{\alpha 0}}{m_{\alpha}} e^{ -y^2 } \, dy \sqrt{ \frac{2k_{B}T_{\alpha 0}}{m_{\alpha}} } \right. +  \\[.8em]
  &\ \ \ \ \ + \left. \frac{k^4}{\omega_{R}^4}  \int_{-\infty}^{\infty} y^4 \left( \frac{2k_{B}T_{\alpha 0}}{m_{\alpha}} \right)^2 e^{ -y^2 } \, dy \sqrt{ \frac{2k_{B}T_{\alpha 0}}{m_{\alpha}} }\right] = \\[.8em]
 &= - \frac{n_{\alpha 0}\cancel{ m_{\alpha}^{3/2} }}{ \sqrt{ 2\pi }  \cancel{ \left( k_{B}T_{\alpha 0} \right) ^{3/2} }} \frac{k^2}{\omega_{R}^2} \left( \frac{2\cancel{ k_{B} T_{\alpha 0} }}{\cancel{ m_{\alpha} }} \right)^{3/2} \left[ \int_{-\infty}^{\infty} y^2 e^{ -y^2 } \, dy  \right. +  \\[.8em]
  &\ \ \ \ \ + \left. \frac{k^2}{\omega_{R}^2} \frac{2k_{B}T_{\alpha 0}}{m_{\alpha}} \int_{-\infty}^{\infty} y^4 e^{ -y^2 } \, dy \right] = \\[.8em]
 &= - \frac{2n_{\alpha 0}}{ \sqrt{ \pi }} \frac{k^2}{\omega_{R}^2} \left[ \frac{\sqrt{ \pi }}{2} + \frac{k^2}{\omega_{R}^2} \frac{2k_{B}T_{\alpha 0}}{m_{\alpha}} \frac{3 \sqrt{ \pi }}{4} \right] = \\[.8em]
 &= - n_{\alpha 0} \frac{k^2}{\omega_{R}^2} \left[ 1 + 3 \frac{k^2}{\omega_{R}^2} \frac{k_{B}T_{\alpha 0}}{m_{\alpha}} \right]
\end{align}
$$
So we can substitute this result in
$$
\begin{align}
D_{R} &= 1+ \sum_{\alpha} \frac{\omega_{p, \alpha}^2}{k^2 n_{\alpha 0}} \cdot P \int_{-\infty}^{\infty} \frac{k}{\omega_{R}}\frac{\partial F_{\alpha 0} (u) / \partial u}{1 - \frac{uk}{\omega_{R}}} \, du = \\[.8em]
&= 1+ \sum_{\alpha} \frac{\omega_{p, \alpha}^2}{\cancel{ k^2 n_{\alpha 0} }} \cdot \left\{ - \cancel{ n_{\alpha 0} } \frac{\cancel{ k^2 }}{\omega_{R}^2} \left[ 1 + 3 \frac{k^2}{\omega_{R}^2} \frac{k_{B}T_{\alpha 0}}{m_{\alpha}} \right] \right\} = \\[.8em]
&= 1- \sum_{\alpha} \frac{\omega_{p, \alpha}^2}{\omega_{R}^2} \cdot \left[ 1 + 3 \frac{k^2}{\omega_{R}^2} \frac{k_{B}T_{\alpha 0}}{m_{\alpha}} \right] = \\[.8em] 
&= 1- \sum_{\alpha}\left[ \frac{\omega_{p, \alpha}^2}{\omega_{R}^2} + 3 \frac{\omega_{p, \alpha}^2}{\omega_{R}^2} \frac{k^2}{\omega_{R}^2} \frac{k_{B}T_{\alpha 0}}{m_{\alpha}} \right] = \\[.8em]  
 &= 1- \sum_{\alpha}\left[ \frac{\omega_{p, \alpha}^2}{\omega_{R}^2} + 3 \frac{\omega_{p, \alpha}^4}{\omega_{R}^2} \frac{k^2 v_{th,\alpha}}{\omega_{R}^2\omega_{p,\alpha}^2} \right] = \\[.8em]
 &= 1- \sum_{\alpha}\left[ \frac{\omega_{p, \alpha}^2}{\omega_{R}^2} + 3 \frac{\omega_{p, \alpha}^4}{\omega_{R}^4} k^2 \lambda_{D \alpha}^2 \right] 
\end{align}
$$
and finally
$$
\begin{align}
D_{R} &= 1 - \frac{\omega_{p i}^2}{\omega_{R}^2} \left( 1+ 3\frac{\omega_{p i}^2}{\omega_{R}^2} k^2 \lambda_{D i}^2 \right) - \frac{\omega_{p e}^2}{\omega_{R}^2} \left( 1+ 3\frac{\omega_{p e}^2}{\omega_{R}^2} k^2 \lambda_{D e}^2 \right) \approx \\[.8em]
&\approx 1 - \frac{\omega_{p e}^2}{\omega_{R}^2} - 3 \frac{\omega_{p e}^4}{\omega_{R}^4} k^2 \lambda_{D e}^2 = 0
\end{align}
$$
Where we used
$$
 \frac{\omega_{p i}^2}{\omega_{p e}^2} = \frac{m_{e}}{m_{i}} \approx \frac{1}{2000}
$$
Now we write it as
$$
\omega_{R}^4 - \omega_{p e}^2 \omega_{R}^2 - 3 \omega_{pe}^4 k^2 \lambda_{D e}^2 = 0
$$
and we solve for 
$$
\begin{align}
\omega_{R}^2 &= \frac{1}{2} \left[ \omega_{pe}^2 \pm \sqrt{ \omega_{pe}^4 + 12 \omega_{pe}^4 k^2 \lambda_{De}^2 } \right] = \\[.8em]
 &= \frac{\omega_{pe}^2}{2} \left[ 1 \pm \sqrt{ 1 + 12 k^2 \lambda_{De}^2 } \right] \approx \\[.8em]
&\approx \frac{\omega_{pe }^2}{2} \left[ 1 \pm \left( 1+6k^2 \lambda_{De}^2 \right)  \right] 
\end{align}
$$
Where in the last passage we used the assumption of
$$
k^2 \lambda_{De}^2 \ll 1
$$
(we will discuss more in detail about this condition later)

Now, the solution with the minus sign gives an imaginary solution for the real part of $\omega$ and is not physical.
The solution with the plus sign gives
$$
\begin{align}
\omega_{R}^2 &= \frac{\omega_{pe }^2}{2} \left[ 2+6k^2 \lambda_{de}^2 \right]= \\[.8em]
 &= \omega_{pe}^2 \left[ 1+3k^2 \lambda_{De}^2 \right]  \\[1em]
\implies \omega_{R} &= \pm \omega_{pe } \sqrt{ 1+3k^2 \lambda_{De}^2 } 
\end{align}
$$
If we compare it to the isothermal fluid case
$$
\omega_{R} ^{(\text{fluid})} = \pm \omega_{p} \sqrt{ 1+k^2 \lambda_{De}^2 }
$$
or with the adiabatic fluid case
$$
 \omega_{R}^{(\text{fluid})} = \pm \omega_{p} \sqrt{ 1 + \gamma_{E}k^2 \lambda_{De}^2 }
$$
So in kinetic theory we have a $\gamma_{E} = 3$, this is linked with the degree of freedom.
Having $\gamma_{E} = 3$ it means that we only have one degree of freedom. 

Now, we work with 
$$
\omega_{I} = - \frac{D_{I}(k, \omega_{R})}{\partial D_{R} / \partial \omega_{R}}
$$
with 
$$
 D_{R}(k, \omega_{R}) \approx 1- \frac{\omega_{pe}^2}{\omega_{R}^2} \left( 1+ 3 k^2\lambda_{De}^2 \frac{\omega_{pe}^2}{\omega_{R}^2} \right) 
$$
where we assume the second term in the parenthesis as small. 
We remember that 
$$
D_{I} = -\pi\sum_{\alpha} \frac{\omega_{p, \alpha}^2}{k^2 n_{\alpha 0}} \cdot  \left. \frac{ \partial F_{\alpha 0}(u) }{ \partial u }  \right|_{\omega_{R} / k}
$$
and we evaluate
$$
\frac{ \partial D_{R} }{ \partial \omega_{R} } = \frac{ \partial  }{ \partial \omega_{R} } \left( -\omega_{pe}^2 \omega_{R}^{-2} \right) = 2\frac{\omega_{pe}^2}{\omega_{R}^3} 
$$
So we can write $\omega_{I}$ as 
$$
 \omega_{I} = + \left. \frac{\omega_{R}^3}{2\omega_{pe}^2} \frac{\pi \omega_{pe}^2}{k^2 n_{0}} \frac{ \partial F_{e 0}(u) }{ \partial u }  \right|_{\omega_{R} / k}  \propto \left. \frac{ \partial F_{\alpha 0}(u) }{ \partial u } \right|_{\omega_{R} / k} 
 $$
