# Notes for Plasma Physics course
This repository contains all my Obsidian notes for the course "Plasma Physics" held by Professor Fracesco Valentini and Professor Sergio Servidio at University of Calabria, during the Academic year 2025/26.

In this repository you will find:
- The map for the part of Prof. Servidio progam
- The map for the part of Prof. Valentini progam
